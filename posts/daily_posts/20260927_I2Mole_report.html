I2Mole：把“分子对”变成可干预的关系图

显式跨分子边找到相互作用核心，离散环境重组检验预测能否跨药物迁移。

每日深度论文追踪 2026-09-27 ICLR 2026

Transductive ACC 只领先最强基线 0.42–0.66 pp，但去掉 VQ 环境模块会损失 14.12 pp；最严格 Zhang Type 2 的 F1 仍仅 39.95。

一句话核心定位： I2Mole 不再把两个药物各自编码后才做匹配，而是先显式建立跨分子原子关系，再用信息瓶颈抽取相互作用核心、用离散环境码做反事实重组，以提升新药与新药对上的 DDI 泛化。

2. Motivation：真正的痛点不是“同分布分数还不够高”

DDI 预测最常见的隐含捷径，是让每个药物先产生一个身份化向量，再在训练集中记住哪些药物或骨架经常与标签共现。若随机拆分的是“药物对”，同一个药物仍可能同时出现在训练与测试中；此时模型可以利用药物身份和骨架频率，而不是学习可迁移的相互作用机制。论文将测试拆成三层：transductive 中两药均见过；inductive Type 1 中只有一个药物见过；Type 2 中两个药物均未见。难度升级在数字上非常清楚：I2Mole 在 ZhangDDI 的 ACC 从 transductive 88.64 降为 Type 1 的 69.12，再降为 Type 2 的 61.35，总落差 27.29 pp（Table 1–2，PDF p.6）。这说明“随机药物对拆分”远不能代表新药部署。

第二个痛点是相互作用本身具有条件性。同一官能团与不同配对分子相遇时，可能通过氢键、疏水作用或范德华力表现出不同贡献。CGIB 已提出“核心子图依赖配对图”，CMRL 将其改写为条件干预，IGIB-ISE 再以 EM 迭代收紧交互子结构；但 I2Mole 认为它们依然没有在图构造层面把跨分子原子—原子关系变成可传播的边。也就是说，过去方法多在“从各自图里找核心”上精进，却没有先搭建一个足够具体的关系空间。

第三个痛点是环境变化的处理。只压缩出核心子图并不自动保证不变性：剩余部分可能携带骨架、大小、药物身份等伪相关。I2Mole 不是简单丢弃环境，而是把非核心表示量化到一个离散 VQ codebook，再随机替换/重组环境码，要求同一核心在不同环境下保持预测。这一设计把“不要依赖环境”转化为可训练的数据增广。

量化证据也显示任务并未解决：在最严格的 ZhangDDI Type 2 上，I2Mole 的 F1 只有 39.95（Table 2，p.6）；即使相对 IGIB-ISE 的 38.62 有 +1.33 pp / +3.44%，绝对表现仍低。论文的强项是小而稳定的泛化改进，不应被描述成 DDI 已达到临床可用。

3. 故事线、核心假设与权衡

论文故事可以压缩为四步。

  1. 先允许一切关系存在。 对两个分子图 (G_1,G_2)，将所有跨分子原子对连成关系边，形成合并图 (G_m)。这样氢键或近程相互作用至少有表示通道，而不是在两个独立图向量合并后才被间接猜测。
  2. 再学习哪些关系值得保留。 关系边经注意力/门控得到权重，低权重边截断，默认保留约 20%；这把全连接关系图收缩为“候选相互作用骨架”。
  3. 从候选骨架中分离核心与环境。 GIB 模块采样任务充分、输入压缩的 rationale (G_{sub})，其余部分为 (G_{env})。
  4. 用离散环境重组训练不变性。 将环境编码到 VQ codebook，采样环境码与核心表示拼接，迫使分类器在环境变动时保持标签。

其核心假设是：给定关系核心后，标签与环境条件独立，即 (Y \perp G_{env}\mid G_{sub})。这比“药物属性只由某个固定子结构决定”更合理，因为核心是对特定配对关系抽取的；但它仍然是建模假设，不是由实验直接证明的因果事实。

权衡也非常明确。全跨分子连边带来二次复杂度；VQ 重组增强了环境覆盖，却可能生成化学上从未出现的核心—环境组合；信息瓶颈提高稳健性，但强度过大时会丢掉任务信息。论文自己给出的相变证据是：β 从最佳 (10^{-4}) 增至 0.1，ZhangDDI ACC 从 88.64 崩至 56.46，下降 32.18 pp（Table 5，p.8）。

4. 方程级形式化与流程

设分子图 (G_i=(V_i,E_i,X_i))，标签为 (Y\in{0,1})。合并图加入跨分子候选边

[ E_{12}={(u,v):u\in V_1,v\in V_2},\qquad G_m=(V_1\cup V_2,E_1\cup E_2\cup E_{12}). ]

局部键内信息由 GatedConv 传播，跨分子关系由 GAT 更新；关系边 (e_{uv}) 产生重要度 (a_{uv})，再按比例 ρ 保留。论文的主配置为 ρ=20%，但 Table 9（p.22）显示 5%–30% 的 ACC 仅在 88.52–88.64 间波动，这意味着阈值并不尖锐。

GIB 的理论目标（Eq. 1，p.2）为

[ \min_{G_{sub}} -I(Y;G_{sub})+\beta I(G_m;G_{sub}), ]

即保留对标签有用的信息，同时压缩对原图的依赖。论文进一步以

[ Y\perp G_{env}\mid G_{sub} ]

表达不变性条件（Eq. 2–3，p.2）。环境编码 (z_e=f_{env}(G_{env})) 被指派到最近的码字

[ q(z_e)=e_{k^},\quad k^=\arg\min_k|z_e-e_k|_2^2, ]

再从 codebook 采样环境码 (e_j)，与核心表示 (z_c) 拼接后预测 ŷ。总损失（Eq. 24，p.6）是

[ \mathcal L_{total}=\mathcal L_{inv}+\mathcal L_{pre}+\beta\mathcal L_{MI}+\gamma\mathcal L_{vq}. ]

其中 ℒpre 是原样本 BCE，ℒinv 是环境重组样本的预测约束，ℒMI 实现瓶颈，ℒvq 更新离散码本。

输入：药物图 G1,G2；标签 y；保留比例 ρ；环境采样数 θ
1  在 G1、G2 内分别运行 3 层 GatedConv
2  加入所有跨分子原子对关系边，并运行 3 层 GAT
3  估计跨分子边权；仅保留 top-ρ 关系边
4  GIB 采样核心子图 G_sub；其余视作 G_env
5  将 G_env 编码并量化到 VQ codebook
6  从 codebook 采样 θ 个环境码，与同一核心表示重组
7  同时最小化原样本预测、重组不变性、互信息与 VQ 损失
输出：DDI 概率与可解释的核心关系子图

7.4 跨域泛化

以 ZhangDDI 训练、在 ChChMiner 和 DeepDDI 测试时，I2Mole 的 ACC 为 59.25 / 58.12，IGIB-ISE 为 57.06 / 57.21，绝对提升 +2.19 / +0.91 pp（Table 3，p.7）。论文报告平均 ACC 提升 2.71%，但跨数据集标签构造、负样本采样与药物重叠可能不一致；这更像“数据源迁移”，不等于跨医院或前瞻临床外推。

第一结论：最大贡献来自 VQ 环境模块，而不是论文标题最强调的跨分子边。VQ 被移除造成的 ACC 损失是去掉跨交互损失的 3.42 倍。第二结论：跨分子交互与 GIB 的边际量级相近。第三结论：这些是“去掉一个模块”的联合系统消融，模块间可能互补；不能把 14.12、4.13、3.92 直接相加当作独立贡献。

Table 11（p.23）把 VQ 环境重组换成随机噪声：Random Distribution 在 Zhang/ChCh/Deep 的 ACC 为 87.21/93.47/92.39，In-distribution noise 为 88.02/94.27/94.56，完整 VQ 为 88.64/95.34/96.51。这说明“任何噪声正则”解释不了全部收益，尤其 DeepDDI 上 VQ 对随机噪声有 +4.12 pp；但仍未与同参数量、可学习连续环境模型 head-to-head。

9. 超参敏感性、规模相变与统计显著性

瓶颈强度 β： (0,10^{-5},10^{-4},10^{-3},0.1) 的 Zhang ACC 分别为 85.71、85.84、88.64、86.83、56.46（Table 5，p.8）。(10^{-4}) 是窄峰，0.1 发生灾难性压缩。这不是“越强越不变”，而是典型的信息保留—去伪相关相变。

VQ 权重 γ： (2\times10^{-5}) 到 (10^{-3}) 的 ACC 只在 88.21–88.64 范围内（Table 5，p.8），说明性能对 γ 相对平坦。论文未给 codebook size 图的精确逐点数字，只说明 10 个码字最佳；本报告不从图像猜读数值。

关系边比例： 5%、10%、20%、30%、50% 的 ACC 为 88.52、88.60、88.64、88.54、88.34（Table 9，p.22）。20% 最好，但 5% 仅低 0.12 pp；这提示关系边排序可能比保留精确比例更重要。

环境采样数 θ： Table 10（p.23）比较 2–6 个环境样本，θ=4 最优；收益不是单调，过多重组可能引入不合理组合。论文报告均值/标准差，但未为该超参曲线做多重比较校正。

模型规模： 23.4M 到 49.0M 参数时 ACC 依次为 83.61、85.94、87.43、88.27、88.64、88.64、88.35、87.91、86.87（Tables 12–13，p.24）。性能在 35.4–38.4M 达平台，继续增大反而下降；训练时间从 7.4h 增至 22.3h。这是一条明确的过参数化拐点，而不是缩放律。

显著性： Appendix Table 8（p.22）给出与第二名的独立 t 检验：Zhang 88.08±0.26 vs 88.64±0.24，(p=3.52\times10^{-4})；ChCh 94.92±0.21 vs 95.34±0.19，(p=2.13\times10^{-3})；Deep 95.85±0.19 vs 96.51±0.14，(p=8.74\times10^{-5})。三项均小于 0.01，但论文未说明正态性、方差齐性、配对与否，也未对多数据集/多指标做校正。统计显著不代表部署意义大：ACC 绝对增量仍只有 0.42–0.66 pp。

10. 效率与复现现实

Table 14（p.25）显示 I2Mole 为 35.4M 参数，在 ZhangDDI 上训练 13.23h、占 17.0GB；CGIB 为 11M、1.50h、5.1GB。因此 I2Mole 参数约 3.22×、训练约 8.82×、显存约 3.33×，换取 transductive ACC +1.32 pp。在 DeepDDI 上 I2Mole 训练 33.07h，CGIB 3.73h，同样约 8.87×。

Table 16（p.26）用更轻骨干替换主网络：GIN 达到 ACC 91.35，训练 188.10s、测试 19.27s；主配置为 95.34、1020.62s、90.61s。GIN 训练快 5.43×、测试快 4.70×，代价为 −3.99 pp。这说明方法不是只能搭配重骨干，但实际应用应画“准确率—延迟—显存”帕累托前沿，而非只报主配置。

11. 真正贡献、可复用设计与迁移潜力

真正贡献一：关系先验前移。 过去模型在各自分子图编码后才交互，I2Mole 让跨分子关系进入消息传递。该设计可迁移到溶质—溶剂、药物—靶标、材料组分配对，但必须用几何或距离先验控制全连接边数。

真正贡献二：把环境从“要丢掉的残差”变为“可采样的变量”。 VQ codebook 给出了可操作的环境替换接口。更一般地，任何存在核心—背景分解的图任务，都可尝试对背景做离散量化，再进行受约束的反事实重组。

真正贡献三：证据链较完整。 主结果、Type 1/2、跨域、消融、β/γ、关系比例、采样数、噪声替代、规模、效率、额外回归任务以及 t 检验同时出现，允许读者识别“收益来自哪里、代价是什么”。

可复用设计不是“照搬所有模块”，而是三条原则：先显式建模对象间关系；把可能的伪相关环境显式参数化；用严格实体不相交划分验证关系是否可迁移。对蛋白—配体可将全连接边换成半径图；对材料混合物可将环境码限定为温度、浓度或晶相条件；对临床多药场景则需从二元图推广到超图。

12. 论文自述限制

  1. 只建模药物对。 论文指出共病患者常同时服用多种药物，而当前框架只处理二元关系；需要推广到高阶多药交互（Limitations，PDF p.25）。
  2. 全连接跨分子边会扩张。 大分子时所有原子对连边带来显著计算量，作者建议设计稀疏交互机制（Limitations，p.25）。
  3. 缺少物理环境变量。 药物功能受温度、pH 等条件影响，当前输入并未显式纳入（Limitations，p.26）。

13. 独立批判：证据—推论链

  1. [归因] 因为去掉 VQ 使 ACC 下降 14.12 pp，而去掉跨交互只下降 4.13 pp（Table 4，p.8），所以论文标题所强调的 interaction-aware 不是主增益的唯一、甚至不是最大来源；更准确的归因应是“离散环境增广主导、关系图补充”。
  2. [外部有效性] 因为最严格 Zhang Type 2 的 F1 仅 39.95（Table 2，p.6），所以即便相对基线显著，模型对两种全新药物的正类识别仍弱，不能由 transductive 的 88.64 ACC 推断真实新药安全性。
  3. [效率] 因为 I2Mole 相对 CGIB 在 ZhangDDI 训练时间约 8.82×、参数 3.22×，而 ACC 只高 1.32 pp（Tables 1、14），所以资源受限筛选系统可能更适合 CGIB/轻骨干；论文需要成本归一化排名。
  4. [因果性] 因为 (Y\perp G_{env}\mid G_{sub}) 是训练假设，VQ 码字也没有与真实温度、pH、剂量或酶代谢通路对齐，所以“环境干预”只能称表示级增广，不能被解释成真实化学干预。
  5. [对照充分性] 因为 VQ 比随机噪声更好，但没有与同容量的连续混合模型、可学习高斯环境或 shuffled-but-valid scaffold 对照，所以不能确定收益来自离散语义、额外参数，还是更合适的噪声分布。
  6. [统计] 因为论文做了三数据集、多指标、多设置的大量比较，却只对三项 ACC 给独立 t 检验且未说明配对/校正，所以“显著性”覆盖面有限；更稳妥的是 8 seeds 配对检验、效应量、置信区间和 Holm 校正。
  7. [数据划分] 因为 Appendix 的训练比例实验同时改变训练/测试样本数量（test 从 45% 降到 5%），ACC 从 53.27 升到 92.25（Tables 12–13，p.24）混合了更多训练数据与更小测试集的效应，所以不能把曲线纯粹解释为样本效率。
  8. [复现] 因为 PDF 给出的 anonymous.4open 代码本次无法访问，且超参段出现“initial LR (10^{-4})”与“increased to 0.5”的可疑表述，所以目前不能确认最终实现细节；正式匿名解除后的稳定仓库与 commit hash 是必要补充。

14. 相关工作：问题来源与技术传递

14.1 MoleOOD：从“环境变化”提出不变子结构

解决什么： MoleOOD 观察到 scaffold、size 等环境改变会破坏分子属性预测，学习环境划分和环境不变子结构；NeurIPS 正式摘要报告在 OGB/DrugOOD 上最高 ROC-AUC 提升 5.9%/3.9%（正式页，摘要；全文为 NeurIPS 2022）。
遗留缺口： 它以单分子属性为主，不回答“同一分子在不同配对对象下哪个部分变成核心”。
I2Mole 如何回应： 把不变子结构从单对象提升到条件于配对对象的关系核心。
设计如何传递： “环境推断 + 不变学习”传成 I2Mole 的核心/环境分解和环境重组；不同点是环境被 VQ 离散化。

14.2 CGIB：把信息瓶颈带入分子关系学习

解决什么： CGIB 让一个分子的核心子图依赖配对分子，用条件图信息瓶颈寻找最小充分子图（ICML 2023 PDF p.1–2）。
遗留缺口： 重点仍是从两个原图压缩核心，跨分子原子关系没有作为显式边进入统一图；环境残差被压缩而不是系统采样。
I2Mole 如何回应： 先建立关系图，再做 GIB；保留 CGIB 的“配对条件核心”，同时为残差增加可采样的 VQ 表示。
设计如何传递： 条件互信息目标直接成为 I2Mole 的理论底座之一。

14.3 CMRL：从相关核心转向条件因果子结构

解决什么： CMRL 构造 SCM，把因果子结构 (C_1)、shortcut (S_1)、配对分子 (G_2) 与标签联系起来，并用条件干预/后门调整减少 shortcut 影响（KDD 2023 PDF p.1–4）。
遗留缺口： “因果”主要发生在表示空间，干预环境仍由模型生成；关系物理没有显式图结构。
I2Mole 如何回应： 用 VQ 环境码实现更直接的可替换环境，并用跨分子边承载关系。
设计如何传递： “核心在不同 shortcut 下预测应稳定”被转写为重组环境下的不变损失。

14.4 IGIB-ISE：用 EM 迭代收紧交互子结构

解决什么： IGIB-ISE 将交互子结构视作潜变量，以 EM 的 E/M 步迭代耦合两个分子的子结构，并用 Interactive GIB 保证最小充分（ICLR 2025 PDF p.2–7）。
遗留缺口： 迭代抽取提高了子结构精度，但对分布环境的显式生成不足；计算链也更复杂。
I2Mole 如何回应： 采用一次关系图构建 + GIB + VQ 重组的模块化路线；Type 1/2 表中以 IGIB-ISE 为最强直接基线。
设计如何传递： 从“核心必须由双方共同决定”传到跨分子注意力和关系边筛选。

14.5 非线性技术演进树

                         ┌─ MoleOOD：未知环境 → 不变子结构
环境/OOD ────────────────┤
                         └──────────────┐
                                        ├─ I2Mole：VQ 环境码 + 重组不变性
信息瓶颈 ─ GIB ─ CGIB：配对条件核心 ────┤
                                        │
因果分支 ─ CMRL：条件干预/shortcut ─────┤
                                        │
交互抽取 ─ IGIB-ISE：EM 迭代耦合 ──────┘
                                                │
                                                └─ 显式跨分子边 + 核心/环境联合建模

演进动力有三个转折：从 IID 随机拆分转向实体不相交 OOD；从固定分子核心转向“随配对对象变化”的条件核心；从丢弃背景转向生成/采样背景以近似干预。I2Mole 的新意不是发明每一条支线，而是把它们接到同一张关系图上。

15. 开放挑战：可操作的 head-to-head 实验空白

理论

  1. 离散环境是否真的逼近干预？ 在相同参数量、同一 GNN、同一 split 下比较 VQ、连续 VAE、conditional normalizing flow 与真实 scaffold/assay 环境标签；报告 OOD ACC、HSIC 独立性、码字—已知化学条件互信息。若 VQ 只在 ACC 领先而码字无语义，就只能称增广。
  2. 何时满足条件独立？ 在合成 DDI 中控制核心因果强度与 shortcut 强度，比较 I2Mole、CMRL、IGIB-ISE 的恢复率；同时测被选核心的 precision/recall，而非只测标签预测。
  3. 高阶多药关系。 构造三元与四元相互作用超图，head-to-head 比较 pairwise 聚合、超图 GNN 与 set transformer；固定总参数与训练对数，测试只有高阶组合未见时的泛化。

工程应用

  1. 稀疏边的真实帕累托。 比较全连接+剪枝、3D 距离半径图、局部敏感哈希候选边与 learned top-k；在相同 A100 上报告 molecules/s、峰值显存、P95 延迟、Type 2 F1。目标不是单点最优，而是找每种分子大小的拐点。
  2. 校准与临床阈值。 在类别不均衡数据上比较 I2Mole、IGIB-ISE、CGIB 的 PR-AUC、Brier、ECE、灵敏度@95%特异度；用时间切分或药品批准年份切分，避免随机数据泄漏。
  3. 可复现性审计。 用作者最终仓库和独立重实现各跑 8 seeds，锁定 commit、CUDA、数据哈希；复核 Table 1 的 MDF-SA-DDI AUROC 与学习率表述，并报告差异。

新兴方向

  1. 2D 关系边 vs 3D 物理关系。 在有构象集合的数据上比较纯 2D I2Mole、3D 等变网络、2D+3D 融合；控制 conformer 数，测试未见 scaffold 和未见构象双重 OOD。
  2. 基础模型能否替代关系图？ 冻结同一蛋白/分子 foundation encoder，比较 late fusion、cross-attention、I2Mole 关系边与检索增强；以单位 GPU-hour 的 Type 2 F1 评估，而非只看最大模型。
  3. 不确定性与拒答。 给 I2Mole 加深度集成、Laplace 或 conformal prediction，在 Type 2 新药对上比较 coverage-width、选择性风险和错误报警；验证“知道自己不知道”是否比 +1 pp ACC 更有部署价值。

16. 近期工作雷达（经验证链接）

  1. GenRel-DDI: Rethinking Drug-Drug Interaction Modeling as Generalizable Relation Learning（2026）：把表示中心从药物身份转向关系本身，直接挑战“扩大分子编码器即可泛化”的假设；非常适合作为 I2Mole 的关系表征对手。
  2. Cross-Domain Molecular Relational Learning（2026）：通过结构—语义迁移处理跨域 MRL，补上 I2Mole 主要在同模态分子图内建模的缺口。
  3. BOOM（2025）：系统比较 140+ 模型—任务组合，发现最佳模型平均 OOD 误差仍是 ID 的 3 倍；提醒不要用单一 DDI split 宣称普遍 OOD 稳健。
  4. SigmaDock（ICLR 2026）：用刚体片段 SE(3) 扩散把结构化化学先验引入 docking，是“先把物理关系空间设计好”这一路线的强例子。
  5. ProTDyn（ICLR 2026）：统一蛋白构象系综与多时间尺度动力学；对 I2Mole 的启示是环境不应只做静态 codebook，还可做动力学状态。
  6. SC-Arena（ICLR 2026）：以知识增强评估单细胞自然语言推理，强调 AI4Science 不只要分数，还要生物学证据链。
  7. AntigenLM（ICLR 2026）：保持基因组功能单元完整性的预训练显著优于打乱/碎片化，和 I2Mole 的共同主题是“正确的结构单位比盲目扩大模型更重要”。

17. 结论

I2Mole 值得读，不是因为它把 transductive ACC 推高了不到 1 pp，而是因为它把“关系如何形成”和“环境如何变化”都暴露为可训练对象。最关键的实证不是单一 SOTA，而是三组互相制约的数字：完整模型相对最强基线的 ACC 只高 0.42–0.66 pp；去掉 VQ 却损失 14.12 pp；相对 CGIB 的训练成本约 8.82×。这三者共同说明：离散环境重组可能是有效的稳健化机制，但它的归因、效率和化学有效性仍需更严格对照。

对研究者，最可复用的是“关系图 + 核心/环境分解 + 环境重组”的接口化设计；对应用者，最应警惕的是严格 Type 2 的低绝对 F1、代码链接不可用以及缺少校准/前瞻验证。把它当作稳健分子关系学习的工程蓝图是合理的，把它当作临床 DDI 判定器则证据远远不够。
