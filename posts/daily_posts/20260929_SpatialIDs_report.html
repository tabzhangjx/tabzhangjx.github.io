2. Motivation：准确率之外，VLM 到底“在哪里”丢掉了空间关系？

经典空间评测已经说明症状，却不能定位病灶。Kamath et al. 在 18 个视觉语言模型上做受控位置测试；经 VQAv2 微调的 BLIP 在受控集合上只有 56%，而人类是 99%（EMNLP 2023 论文摘要/正文第 1–2 页）。这个 43 pp 差距并不自动意味着模型“看不见”：它可能看到了两个对象，却没有把对象与方位绑定；也可能视觉编码器已编码方位，但跨模态投影丢失；还可能中间层有正确表征，语言输出阶段却读错。

主论文把问题拆成三个可证伪层次：

  1. 表征存在性。 给定同一对象在不同格子中的图像，能否从对象 token 的隐藏状态线性解码位置？
  2. 因果性。 如果把“左边对象”的空间表征替换成“右边对象”的表征，答案是否按预测翻转，而不是只发生无意义扰动？
  3. 错误定位。 模型答错时，错误已存在于视觉编码器，还是后来才发生于图像—文本绑定？

这三个层次的关键区别是：线性可分不等于模型使用该方向，相关不等于因果。论文因此组合了 probe、mirror patching、arbitrary steering、视觉/文本对称诊断与训练时辅助损失。最重要的量化动机来自因果实验：对“左/右”空间 ID 做 steering 后，二元信念翻转中位数为 64.6%，随机噪声对照为 29.5%（主论文第 5 页，正文约第 295–307 行）；论文报告相对机会水平的平均增量为 43.6%。这说明读出的方向不仅能分类，还参与了模型最终判断。

但需要先埋下一条谨慎线：论文图注/摘要附近写 64.4%，主结果正文写 64.6%，存在 0.2 pp 内部不一致；本报告以主结果正文 64.6% 为主，同时保留冲突。它不改变定性结论，却说明精确复现实验时不能只抄摘要。

3. 论文故事线、核心假设与权衡

3.1 故事线

论文的故事不是“又发现一条神经元”，而是从语言模型实体绑定机制迁移到多模态：Feng & Steinhardt 发现语言模型可用可加、可交换的 binding ID 把实体和属性绑定；主论文猜测 VLM 也可能给每个空间槽位一个 ID，把对象内容与其位置结合。于是作者先在 4×4 网格合成图中控制对象与位置，再训练线性方向，最后跨层和跨模态做补丁。

若假设成立，应同时观察到：

  • 对象 token 中的位置可以被低秩线性子空间读出；
  • 左右/上下方向具有近似一致的几何结构；
  • 把 ID 从一个对象转移到另一个对象，会改变与该对象相关的答案；
  • 正确图像状态与错误文本状态的镜像补丁能把错误归因到编码或绑定阶段；
  • 把 ID 结构作为训练损失，应该比同数据的纯语言建模更快获得空间准确率。

实验大体支持这条链，但支持强度逐级下降：表征存在与简单二元干预证据最强；训练收益只有一个小规模 LLaVA 设定；时间机制主要是定性曲线；复杂深度关系会混淆。因此最恰当的结论是“简单空间—时间关系中存在可操纵的线性绑定机制”，而不是“VLM 的空间推理已被统一解释”。

4. 方程级形式化

4.1 隐状态与信念变化

设图像含对象 (o_a,o_b)，模型在层 (ell) 的对象相关隐藏状态为 (h_{o}^{(\ell)})。对二元答案 (y^+,y^-)，定义 logit 信念差：

[ B(x)=z(y^+\mid x)-z(y^-\mid x). ]

对隐藏状态施加干预 (I) 后，论文用

[ \Delta B = B(I(x))-B(x) ]

测量 steering，而不是只看最终 0/1 是否翻转。这样能保留“朝正确方向移动但未过决策边界”的信息（主论文 Eq. 1，第 3 页）。

4.2 空间 ID 的构造

对位置 (p=(i,j)) 与对象 (o)，收集对象 token 表征 (h_{o,p}^{(\ell)})。通过跨对象平均消去对象语义：

[ s_{p}^{(\ell)} = \mathbb{E}{o}[h{o,p}^{(\ell)}] - \mathbb{E}{o,p'}[h{o,p'}^{(\ell)}]. ]

左右方向可由两组位置均值之差得到：

[ d_{LR}^{(\ell)} = \mathbb{E}{p\in L}[s_p^{(\ell)}]-\mathbb{E}{p\in R}[s_p^{(\ell)}], ]

上下方向 (d_{UD}^{(\ell)}) 同理。论文还用岭回归把位置编码 (psi(i,j)) 映射到空间 ID：

[ \hat{s}_{i,j}^{(\ell)} = W^{(\ell)}\psi(i,j)+b, ]

并考察低秩约束 (\operatorname{rank}(W)\le r)。当 (r=3) 时，三种模型的 (R^2) 均不低于 0.854（附录 Table 2，第 20 页附近；见第 7 节数据矩阵），支持“二维位置主要落在很低维子空间”这一具体而非泛化过度的主张。

4.3 机制近似

论文的理论草图把对象位置表征近似为注意力值投影：

[ s_{i,j}\approx W_O W_V P\left(\psi(i,j)-\bar{\psi}\right), ]

其中 (P) 表示跨模态投影，(W_V,W_O) 是注意力值与输出投影。最终关系 logit 又近似为线性读出：

[ z_r \approx w_r^\top (s_{i,j}-s_{i',j'})+c_r. ]

这两式解释为何“位置编码 → 低秩空间 ID → 关系 logit”可能串成线性链。但它是机制草图，不是对完整 softmax 注意力、MLP 与残差网络的等式证明；不能据此声称模型全程线性。

4.4 Mirror patching 与 arbitrary steering

镜像补丁构造一对只在关系上相反的样本，例如 A 在 B 左边与 A 在 B 右边。将源样本的对象空间分量注入目标样本：

[ \tilde h_o^{(\ell)} = h_o^{(\ell)} + \alpha\big(s_{p_{src}}^{(\ell)}-s_{p_{tgt}}^{(\ell)}\big), ]

其中论文默认 steering scale (\alpha=5)（附录第 16 页）。arbitrary steering 则无需成对镜像图，直接按目标位置 ID 改写；若输出按目标位置变化，就比“该方向可线性分类”更强。

4.5 训练时空间损失

作者把对象 token 的空间 ID 与目标 ID 对齐，联合语言损失：

[ \mathcal{L}=\mathcal{L}{LM}+\lambda\mathcal{L}{spatial},\qquad \mathcal{L}{spatial}=\sum_o|g(h_o^{(\ell)})-s{p(o)}|_2^2. ]

论文没有报告完整 (\lambda) 敏感性曲线，所以只能说该损失在所选配置中使 3,200 步准确率从 85% 提到 91%，不能推出任意权重均稳定有效。

6. 数据集、基准与指标

6.1 合成 4×4 网格

主诊断集把对象放在离散格子，改变左右、上下、前后/大小等关系。优点是反事实对可以只改位置，适合因果补丁；缺点是分布过于干净。论文 Appendix A.2（约第 12–13 页）给出：基线配置覆盖 90 个对象对 × 4 个尺寸，总计 86,400 张图，画布 896×896；资源中有 55 个 Objaverse 对象渲染。该集合用于线性可读性、ID 数据效率、提示稳健性、尺寸消融与 arbitrary steering。

6.2 COCO-Spatial / WhatsUp 家族

真实图像空间问答用于检查合成方向能否落到自然图像。核心指标是 accuracy；训练实验记录步数、LM loss、spatial ID loss 与 COCO validation accuracy。WhatsUp 原论文的受控基准给出人类 99% 与 BLIP 56% 的历史差距，但两篇论文并非完全相同训练设定，不能把差值当作主论文直接提升。

6.3 MVBench Scene_QA 与倒序视频

作者把视频帧反转，观察模型对事件先后或时序内容的内部表征和答案变化；合成视频固定 8 帧，5 个对象对覆盖 61 种时间排列。MVBench Scene_QA 提供自然视频问答。指标仍是准确率/信念差，但论文没有发布可重建的“5 基准×6 方法”视频矩阵，因此本报告保留空缺，不用图上估读伪造小数。

6.4 指标解释

  • Accuracy： 最终答案正确率，易读但看不到接近决策边界的变化。
  • Belief shift (\Delta B)： 正确与错误答案 logit 差的干预变化，能测方向性因果效应。
  • Variance explained / (R^2)： 低秩位置映射解释空间 ID 方差的比例；高 (R^2) 支持低维结构，不等于对任务准确率的直接保证。
  • Mann–Whitney U： 比较正确/错误样本的干预效应分布。论文报告显著性趋势，但正文没有给出完整精确 p 值、效应量与多重比较校正。

8. 逐层消融、敏感性与可能的相变

8.1 层深

有效 steering 集中在中间层：作者从第 9 层扫到约模型深度的 (2/3)。过浅时视觉与语言尚未形成稳定对象绑定，过深时答案方向已被输出头固化。这个“中间层窗口”与 NAACL 2025 信息流研究的“浅层视觉贡献收敛、深层任务化分化”相呼应，但核心论文没有给出所有模型统一归一化层坐标的数表，因此不能证明跨架构存在精确共同临界点。

更关键的是，附录置信区间由最佳 steering 的三层计算，而不是预注册层或所有层平均。因为先择优再汇报会抬高效应，所以 64.6% 应视为“可达到的中层效应”，不是随机层的期望效果。

8.2 样本量

正文称少至 9 个对象对已能解释至少 50% 空间 ID 方差；图注又列 6/20/56 对象对图像的消融。两种表述可能指训练样本口径不同，也可能是版本编辑不一致。可以肯定的是方向发现样本效率较高，不能肯定的是精确拐点究竟在 6 还是 9。论文未给出每个点的均值±标准差，也未给出不同随机对象子集的稳定性，因此“9 对即可”的置信度有限。

8.3 对象尺寸与提示

用 80/128/176 像素对象替换基础尺寸后，解释方差下降约 10–20%，但仍不低于 50%；不同提示措辞表现相近（附录消融，第 18–19 页）。这排除了“只记住一个像素大小/一个问句模板”的最简单反驳。仍未排除自然图像的遮挡、透视与长尾类别，因为尺寸变化仍是在规则画布中进行。

8.4 方向与深度

左右、上下相对清晰；“above/front”与“behind/below”出现混淆（主文第 6 页）。这是一条重要反证：模型可能把三维深度词映射到二维投影或语料共现方向。若线性 ID 真能统一空间，深度方向应在受控相机变化下保持独立；现在的结果只支持二维布局强、深度弱。

8.5 steering scale

默认 (\alpha=5)，但论文未报告从 0 到更大值的剂量—反应曲线，也未给出隐藏状态范数归一化后尺度。于是不能区分三种可能：小尺度已沿自然因果方向工作；只有大尺度分布外冲击才翻转；或不同模型需要不同尺度。这里不存在可核验的“相变点”，任何阈值说法都应等待复现。

8.6 时间维度

8 帧合成视频、61 种排列和 MVBench 倒序实验显示 temporal ID 的迹象，但论文没有完整帧数 sweep（2/4/8/16/32）、速度变化或长视频延迟测试。故不能推出对长时序记忆有效，更不能把空间低秩结论直接套到时间。

9. 统计显著性与证据强度

论文使用 Mann–Whitney U 检验比较正确/错误或干预/对照分布，并在图中给置信区间；但主文没有系统报告每项的精确 p 值、U 统计量、效应量、样本数、随机种子数量或多重比较校正。训练表也没有均值±标准差。因此：

  • 可以推出干预在作者样本上的方向性差异明显，尤其 64.6% vs 29.5% 的绝对差达 35.1 pp；
  • 不能推出跨随机种子、跨提示、跨对象采样的置信区间稳定；
  • 不能严谨比较 0.2–2 pp 的小差异；
  • “最佳三层”选择使常规置信区间不能自动覆盖模型选择不确定性；
  • 训练 +6 pp 若无多种子，仍可能混入初始化与 batch 顺序效应。

理想复现应以模型×对象子集×提示模板为分层单位，预注册层区间，报告 bootstrap 95% CI、Cliff’s delta 或 rank-biserial effect、Benjamini–Hochberg 校正，并把层选择放入 nested validation。

10. 相关工作：问题来源与技术来源链

10.1 Kamath et al. 2023：从“会看图”到“不会稳定判断上下左右”

解决什么。 构造 COCO-prep、GQA-prep、RealCLEVR 等受控集合，证明 18 个 VL 模型在简单空间关系上远落后人类；BLIP-VQAv2 仅 56% vs 人类 99%。
遗留缺口。 评测告诉我们哪里失败，却无法判断失败发生在视觉识别、跨模态绑定还是语言输出。
核心论文如何回应。 用同一对象的反事实位置、对象 token 空间 ID 与镜像补丁把失败拆到模块和层。
关键设计如何传递。 “受控最小对”从 benchmark 设计传递为因果干预样本；COCO-Spatial 也成为训练与自然图像验证桥梁。

10.2 Feng & Steinhardt 2024：绑定 ID 从文本走向视觉对象

解决什么。 语言模型能以可加 binding ID 把实体与属性绑定；对照准确率 >99%，只干预属性或实体一侧时 <3%，同时干预两侧时恢复到 >97%（论文第 4–5 页）。跨任务方向也有可迁移性，Table 2 中 capitals 0.88、parallel 0.87、shapes 0.71、fruits 0.80、bios 0.47，对照 zeros/random 约 0.30/0.31。
遗留缺口。 纯文本实体—属性是否等同于视觉对象—位置并不清楚，视觉编码器和投影器引入了新瓶颈。
核心论文如何回应。 先跨对象平均抽取空间 ID，再在图像 token 与对象词 token 两侧 patch，并通过视觉/文本对称干预定位错误。
关键设计如何传递。 “ID 可交换 + 双侧一致替换”直接成为空间机制的因果检验骨架。

10.3 Hernandez et al. 2024：关系可线性读出，但线性不是普遍真理

解决什么。 证明部分关系可用单一线性变换近似，从主体表征预测客体；项目同时强调有些模型行为准确但内部关系编码并非线性。
遗留缺口。 工作集中于文本事实关系，没有对象位置与视频顺序，也没有回答“关系方向是否与具体视觉对象绑定”。
核心论文如何回应。 把线性关系读出移到多模态中间层，并用对象级 steering 验证读出方向是否被输出使用。
关键设计如何传递。 线性映射、低秩分析和因果替换被保留；“非线性也可能正确”的警告要求我们不要把 probe 失败等同于表征不存在。

10.4 Zhang et al. 2025：信息流告诉我们看哪一层，未告诉我们哪条变量

解决什么。 追踪 LVLM 不同推理任务中的视觉信息贡献，发现浅层较快收敛、深层随任务分化，并存在任务相关的“cliff layer”（NAACL 2025 Long，第 2289–2299 页）。
遗留缺口。 信息贡献是宏观量，无法说明中间层具体携带对象、位置还是答案先验；相关曲线也不能证明因果。
核心论文如何回应。 以空间 ID 作为具名变量，做对象/文本/图像位置精确 patch。
关键设计如何传递。 跨层扫描被保留，但从“信息多少”升级为“哪种绑定、干预后答案怎么变”。

10.5 Chen et al. 2025 / AdaptVis：注意力焦点修复与 ID 修复的互补

解决什么。 从注意力机制分析空间失败，发现模型对目标对象区域的注意力与成功相关；AdaptVis 在 WhatsUp/VSR 上可带来最高约 50 个绝对百分点的训练零样本提升（ICML 2025 摘要/主结果）。
遗留缺口。 聚焦正确区域仍可能把对象绑定到错误关系；显著注意力也未必是因果载体。
核心论文如何回应。 直接对对象位置 ID 操作，区分视觉编码错误与后续绑定错误。
关键设计如何传递。 两者可以组合：先用 AdaptVis 修“看哪里”，再用 spatial-ID loss 修“对象与位置如何绑定”，形成可测试的串联干预。

11. 真正贡献、可复用设计与迁移潜力

11.1 真正贡献

  1. 把空间失败变成可操纵变量。 相较单纯准确率或注意力热图，空间 ID 有明确的对象归属、方向和可替换操作。
  2. 把表征、因果、诊断、训练串成闭环。 线性读出说明“存在”，steering 说明“被使用”，镜像 patch 说明“在哪里坏”，辅助损失说明“能否修”。很少有机制论文同时走完四步。
  3. 跨架构低秩证据。 rank-3 在 LLaVA、LLaMA3.2-VL、Qwen2.5-VL 上 (R^2=0.854–0.903)，说明至少在受控二维位置上结构不是单模型偶然。
  4. 错误类型可分。 LLaVA 的错误更多与视觉编码/目标检测相关，LLaMA 的错误更像跨模态绑定后出现（主文第 6–7 页）；这直接影响修复策略，而不是一律扩大数据。

11.2 可复用设计

  • 因果最小对生成器： 任何需要比较“同对象、只改关系”的任务都可复用。
  • 对象中心化 ID： 跨对象平均消掉内容语义，适合颜色、计数、时间顺序乃至角色身份。
  • 双侧 mirror patching： 对多模态失败做 encoder vs projector/LLM 分流诊断。
  • 低秩谱作为机制压缩： 在不训练大模型的情况下，先判断一个属性是否有紧凑中间表征。
  • 机制导向辅助损失： 当 LM loss 已饱和而结构损失仍下降时，可用作训练早停或课程信号。

11.3 迁移潜力

最直接迁移是三类：第一，文档理解中把字段与二维版面位置绑定；第二，医学影像中把病灶与象限/器官位置绑定；第三，视频中把实体与事件顺序绑定。更冒险但有价值的是机器人：把视觉对象 ID 与动作坐标系绑定。不过 BridgeVLA 等机器人工作已经表明真实操作含视角变化、控制延迟与长程规划；简单 4×4 ID 只能是局部状态表征，不能替代世界模型。

12. 论文自述限制

  1. 任务简单。 作者明确承认空间问题以简单关系为主，时间问题也偏外观/顺序，不能覆盖组合推理（Limitations，第 8–9 页）。
  2. 模型规模有限。 受算力限制，实验模型不超过约 14B；闭源前沿模型和更大开源模型是否同构未知（Limitations，第 8–9 页）。
  3. 用途尚窄。 论文把更广泛的诊断和训练用途留作未来工作；当前没有生产场景或安全关键验证（Limitations，第 8–9 页）。

13. 独立批判（每点均为“证据 → 推论”）

  1. [统计/选择偏差] 因为置信区间使用“最佳 steering 的三层”而不是预注册层，且论文未报告 nested selection 修正，所以 64.6% 更接近可达峰值而非无偏总体效应，跨模型平均可能被高估。
  2. [内部一致性] 因为图注/摘要附近写 64.4%、主结果正文写 64.6%，对象对样本量又出现“6”与“至少 9”两套口径，所以代码复现应优先于二手数字抄录，精确到 0.1 pp 的比较不可靠。
  3. [因果干预有效性] 因为默认 scale=5 却没有剂量—反应曲线或隐藏范数归一化，所以答案翻转可能部分来自分布外激活；只有展示小尺度单调效应、随机等范数方向和 activation norm 匹配，才能把它稳健解释为空间因果变量。
  4. [外部效度] 因为主要图像是 896×896 规则网格、固定对象尺寸与清晰分离，而真实图像含遮挡、透视和语义共现，所以 (R^2\ge0.854) 不能直接外推到自然场景；尺寸变化后方差解释已下降 10–20%，正是域差敏感性的信号。
  5. [三维语义] 因为 above/front 与 behind/below 已出现混淆，所以所谓“空间 ID”更可能首先编码二维投影和语料关系，而非坐标系无关的三维几何；需要相机姿态反事实才能区分。
  6. [训练归因] 因为 spatial-loss 组与控制组在 1,600 步前完全同分，而到 3,200 步才差 6 pp，且没有多随机种子，所以不能排除优化时序或正则化效应；它尚未证明收益来自作者声称的 ID 几何本身。
  7. [时间证据不足] 因为视频只系统描述 8 帧、5 对象对与 61 排列，且没有完整逐模型数表，所以“时空统一机制”的时间部分弱于空间部分；目前更像概念验证，不足以覆盖长视频记忆。
  8. [规模与封闭模型] 因为实验上限约 14B 且不含前沿闭源模型，所以无法判断低秩 ID 是规模扩大后保留、分裂还是被更复杂非线性表征取代；跨规模结论仍开放。

14. 开放挑战：可操作的 head-to-head 实验空白

14.1 理论

T1：线性 ID 还是局部切线近似？ 同一模型、同一数据上比较 rank-3 线性映射、两层 MLP、kernel ridge 与局部线性模型；保持参数量/验证集一致，在自然图像反事实上同时报告 (R^2)、steering AUC 与分布外位置泛化。若 MLP 只提高 probe 而不提高 steering，线性机制解释更可信；反之应修正“线性”主张。

T2：第三维的含义。 对 rank-1…8 做奇异值谱与跨种子置信区间，并分别用二维坐标、齐次坐标 ((x,y,1))、深度 (z) 预测空间 ID。head-to-head 比较解释方差和可迁移 steering，判断 rank-3 是齐次偏置还是几何深度。

T3：注意力路径 vs 残差路径。 在同一层对 (W_V/W_O)、MLP 和 residual stream 分别做 path patching，与整 token patching 比较 belief shift；若只有整 token 有效，理论草图中的注意力线性链还不充分。

14.2 工程与应用

E1：AdaptVis × Spatial Loss 2×2 因子实验。 在 WhatsUp、VSR、COCO-Spatial 上比较 baseline、AdaptVis、spatial loss、两者组合；同模型同训练预算，报告 accuracy、目标框注意力 IoU、ID (R^2) 与推理延迟。该实验能分离“看哪里”和“绑给谁”的互补性。

E2：自然域鲁棒性。 用固定对象关系创建四组：无遮挡、局部遮挡、相机旋转、背景语义冲突；比较原模型、ID steering、LoRA 微调和全量微调。要求至少 5 seeds 与 bootstrap CI，测相对位置准确率和不相关任务退化。

E3：服务级可用性。 将错误定位器作为运行时守门器：若 encoder error 则重裁剪/重检测，若 binding error 则改写提示或激活修正。与 self-consistency、tool-use detector head-to-head，报告准确率、平均额外 FLOPs、P95 延迟和错误拒绝率。

14.3 新兴方向

N1：长视频 temporal ID。 在 8/32/128/512 帧下比较固定位置 ID、RoPE 时间读出、外部记忆与 streaming VLM；用同一事件反转最小对报告 temporal steering、末段衰减和内存。只有跨 512 帧仍稳定，才能支持长期时间绑定。

N2：三维/具身坐标系。 在同一机器人场景中改变相机但保持世界坐标关系，比较 image-centric ID、camera-centric 3D token 与 world-centric scene graph；指标是关系不变性、抓取成功率和跨相机迁移。此实验直接检验 2D ID 能否升格为动作空间变量。

N3：多对象组合与指代。 从 2 对象扩展到 4/8/16 对象，加入“左边第二个红杯后面的书”之类组合指代；比较单一低秩 ID、slot-based binding 与显式 scene graph。报告随对象数的错误增长率，而不只报告平均准确率。

15. 值得继续跟进的近期工作

  1. PostAlign, ICLR 2026： 把多模态 grounding 当作纠偏透镜，适合与 spatial ID 的“中间表征纠偏”对照；一个改输出对齐，一个改对象—位置绑定。
  2. MetaSpatial, ICLR 2026： 直接面向元宇宙/三维空间推理，是检验本论文二维低秩机制能否外推到相机与世界坐标的自然对手。
  3. SpatiaLab, ICLR 2026： 提供更广泛空间推理评测；可作为避免只在自建 4×4 网格闭环验证的外部基准。
  4. To Sink or Not to Sink, ICLR 2026： 追踪大 VLM 的视觉信息通道，和 spatial ID 的具名变量分析互补；前者回答信息去哪，后者回答哪种变量被绑定。
  5. SPIKE-RL, ICLR 2026： 用 Bayesian surprise 强化 Video-LLM，适合与 temporal ID 比较“主动挑关键帧”与“连续时间绑定”两条路线。
  6. MMR-V, ICLR 2026： 多帧证据推理强调未明说的信息组合，可暴露 8 帧合成顺序任务无法覆盖的跨帧隐含关系。
  7. SpatialVLM, CVPR 2024： 以约 10M 图像、2B VQA 数据训练空间能力；它代表“数据规模”路线，恰好与本论文“机制辅助损失”路线做同预算比较。
  8. AdaptVis, ICML 2025： 最高约 50 pp 的空间基准增益非常醒目，但需要与对象绑定诊断同台，确认提升来自正确注视还是更强提示先验。

16. 最终判断

这篇论文值得看，不是因为它把某个榜单再推高一点，而是因为它提出了一种可复用的机制研究模板：控制变量生成 → 低秩读出 → 因果替换 → 错误定位 → 机制导向训练。最硬的发现是 spatial-ID steering 的 64.6% 中位 belief swap 显著高于随机噪声 29.5%，且 rank-3 位置映射在三种架构上解释 85.4%–90.3% 方差；这让“VLM 以紧凑位置标签绑定对象”从比喻变成可检验假设。

但报告的真正结论应停在“简单二维关系的中间层线性机制”而非“统一时空推理理论”。内部数字有两处小冲突，层选择有择优偏差，scale=5 无敏感性，训练 +6 pp 无多种子，时间实验无完整矩阵，深度关系还出现语义混淆。下一步最有价值的不是继续堆 probe，而是做自然图像、相机变换、长视频与多对象组合上的预注册 head-to-head 因果实验。
