Circuit Insights：从“看激活”走向“看权重与电路”

自动解释不应只写出流畅标签，还要说明固定权重、输入路径与输出后果为何一致。

2. Motivation：真正的痛点不是“看不到激活”，而是“看见了也不知道为什么”

主流自动解释管线先在大语料中寻找某特征的高激活样本，再把文本与逐 token 激活交给另一个 LLM 生成自然语言说明。它把人工检查扩展到数万乃至数百万特征，却埋下四个结构性问题。

第一，激活是相关，不是路径。一个 token 与目标特征同时高激活，不等于该 token 经哪一个注意力头、哪一个上游特征促成了目标特征，也不说明该特征最终改变了哪些输出。核心论文 Figure 9 的 L21F91 就展示了这种错位：输入侧只看到 “on” 或若干动词，输出归因却指向 “the basis of / based on” 之类短语（PDF p.9）。只看激活会把“触发条件”和“功能效果”混在一起。

第二，数据集是隐性超参。论文用同一 Pile-uncopyrighted 来源构造 24M-token 小集与 2.3B-token 大集，两者相差约 95.8 倍；CircuitLens 在大集上的输入指标显著更强，但 24M 集通过电路遮罩加 WeightLens 仍能在 Clarity 上超过 MaxAct*（PDF pp.8,15, Table 3）。这意味着解释质量不仅反映特征，也反映“你碰巧拿什么语料去问它”。

第三，解释器与裁判也是黑箱。CircuitLens 最终仍让 gpt-4o-mini-2024-07-18 合并簇级描述，FADE 的四指标也依赖 LLM-as-a-judge。若解释器和裁判共享语言偏好，就可能把文字流畅度当成机制真实性。论文自己承认 Fully eliminating explainer LLM 仍困难（Limitations, PDF p.10）。

第四，单特征干预未必能测试真实因果作用。转码器特征高度冗余，单个特征被 steering 后，模型可能由平行路径补偿。核心论文 Table 2 的平均 Faithfulness 仅约 0.04，Table 3 的多数方法约 0.03–0.04；这不是“小幅落后”，而是表明当前说明在“能否按描述方向改变输出”上普遍缺证据。

因此，论文的主假设不是“权重天然可解释”，而是更窄、更可检验的两段式判断：对上下文无关特征，异常大的固定权重连接能提供稳定语义；对上下文相关特征，必须把激活拆成具体上游组件与输出后果，再做聚类与描述。

3. 故事线与关键权衡

故事线可压缩为三次转向：

  1. 从神经元到稀疏特征。 SAE 缓解多义神经元，但只重构激活；转码器重构整个 MLP 映射，因此保留“输入激活 × 固定连接”的可分解结构。
  2. 从高激活样本到结构证据。 WeightLens 直接读 encoder/decoder、embedding/unembedding 与跨层 decoder-to-encoder 连接，避免大语料；CircuitLens 则用输入依赖 Jacobian、注意力头归因和输出 logit 归因重建局部电路。
  3. 从单一说明到簇级说明。 先按共享的上游特征与注意力头模式聚类，再逐簇解释并合并，目标是把 polysemantic feature 拆成多个机制簇，而不是强迫一个句子包办全部行为。

代价也一并转移：WeightLens 便宜、无数据依赖，但只覆盖 Gemma 32.7%、GPT-2 58.8%、Llama 25.4% 的可验证 token-based 特征（PDF p.8）；CircuitLens 覆盖上下文机制，却要缓存激活、做反向传播、聚类并调用解释器 LLM，且输出侧每新增 token 都增加前后向开销（Table 1, PDF p.16）。

4. 方程级形式化

4.1 转码器与两类归因

设第 l 层目标转码器特征为 (l,i)，encoder 向量为 f_enc^(l,i)；更早第 l' 层特征 (l',i') 的 decoder 向量为 f_dec^(l',i')，其在 token t 上的激活为 a_(l',i')[t]。最基本的跨特征归因为：

[ A_{(l',i')\rightarrow(l,i)}(t)=a_{(l',i')}(t),\langle f_{dec}^{(l',i')},f_{enc}^{(l,i)}\rangle. ]

前项随输入变化，后项只由权重决定。论文进一步加入局部 Jacobian：

[ A^{J}{(l',i')\rightarrow(l,i)}(t)=a{(l',i')}(t),f_{dec}^{(l',i')}J^{(l\rightarrow l')}(t)f_{enc}^{(l,i)}, ]

其中 J 在给定输入处把注意力、归一化与非线性局部冻结（Eq.2–3, PDF p.3）。这使 CircuitLens 能追踪“某一次运行”里的实际路径，但也意味着它只是局部线性归因，不是全局因果等价。

注意力头 (l',h) 从源 token s 到目标 token t 对特征的贡献写成：

[ A_{h,s\rightarrow i,t}=\operatorname{score}{l',h}(r{pre}[t],r_{pre}[s])\cdot\langle (W_{OV}^{l',h})^Tf_{enc}^{l,i},r_{pre}^{l'}[s]\rangle. ]

输出侧则计算目标特征到预测 token y_t 的 logit 贡献：

[ A_{i\rightarrow y_t}=a_{l,i}[t], f_{dec}^{l,i}J^{y\rightarrow(l,i)}[t]W_U[:,y_t]. ]

前三式分别回答“固定连接是什么”“本次输入经何路径激活”“它把输出推向哪里”。

4.2 WeightLens 流程伪代码

for layer l from early to late:
  for feature i in transcoder(l):
    input_tokens  = zscore_outliers(W_emb · f_enc[l,i], τ_vocab)
    output_tokens = zscore_outliers(f_dec[l,i] · W_U, τ_vocab)
    upstream = union over l'<l of
               zscore_outliers(W_dec[l'] · f_enc[l,i], τ_feature)
    input_tokens += inherit_validated_tokens(upstream)
    validated = {token | forward(token) activates feature(l,i)}
    if validated is empty: mark context-dependent
    else: lemmatize(validated) [+ optional output_tokens / LLM refinement]

词表异常阈值：GPT-2 为 z=4，Gemma-2-2B 与 Llama-3.2-1B 为 z=4.5；跨特征连接阈值 z=3（PDF pp.4–5）。核心假设是：若固定连接真的描述特征的内在 token 语义，则孤立 token 前向验证仍应激活它。

4.3 CircuitLens 流程伪代码

cache max activations over corpus
partition activation distribution into B=20 quantile bins
sample N=100 without replacement with weight w_i = 1 / n_bin^0.9
for each sampled context:
  trace significant upstream features and (head, token, relative-position)
  mask non-contributing input tokens
  optionally trace affected generated tokens
  form sparse contributor set S_j
filter contributors appearing in at least ρ fraction of inputs
compute Jaccard(S_a,S_b)
cluster; explain each cluster with an LLM; merge cluster descriptions

正文写 DBSCAN（PDF p.6），Appendix E.5 写 HDBSCAN、eps=0.7、min_samples=3（PDF p.21）；这一命名不一致是复现时必须先澄清的地方。

6. 数据集、模型、基准与指标

实验涉及 GPT-2 Small、Gemma-2-2B、Llama-3.2-1B 的转码器；定量主图集中在 Gemma-2-2B。语料为去版权版本 Pile，总体超过 345.7 GB，作者切出 6GB/2.3B-token 大集与 40MB/24M-token 小集；训练分区生成解释，测试分区评测，并做句长上下 5% 过滤、去重与纯数字/符号过滤（Appendix B, PDF p.15）。

FADE 四指标均在 [0,1]：

  • Clarity：说明是否足够明确，使 LLM 能合成真正激活该特征的样本。
  • Responsiveness：概念样本激活相对随机/非概念样本能否分开。
  • Purity：自然数据里的高激活是否主要属于说明概念，而非无关样本。
  • Faithfulness：对特征做干预后，输出是否沿说明声称的方向变化。

不能把这四者合成一个“总解释分”。例如 WeightLens 清晰但不纯，说明它常抓到稳定 token 片段，却遗漏上下文条件；Faithfulness 低则意味着自然语言说明还没成为可信的因果证书。

8. 逐层消融、超参敏感性与相变

8.1 WeightLens 逐项消融

Table 2 给出三种组合。单独 WL 的十层平均 Clarity 0.634；加入 output tokens 后，层 0 从 0.67 降到 0.63、层 12 从 0.47 降到 0.38，几乎各层下降；再用 LLM 汇总仅部分恢复。说明未经验证的 unembedding outliers 更像噪声而非免费功能语义。Responsiveness 对 +Out 略有提升，但 Purity 与 Faithfulness没有系统改善。真正有效的部件是“固定连接 + 单 token 前向验证”，不是“把更多词塞进说明”。

8.2 CircuitLens 逐项消融

小数据下，CL-Input 与 CL-Full 的十层平均 Clarity 分别 0.429/0.429，添加输出追踪几乎零平均收益；再融合 WeightLens 才到 0.506。这与 Table 1 的成本形成鲜明对比：15-token 输出侧要额外 12 GPU-hour，却没有在平均 Clarity 上带来收益。大数据 top 设置中，CL-Full 比 CL-Input 的 Clarity 0.618 vs 0.609（本报告计算），有小幅收益；因此输出追踪更适合作为定性功能定位，而非默认全量步骤。

8.3 层深“相变”

WeightLens 可验证比例在 Gemma/Llama 中从早层下降到中层，再在晚层部分恢复；Gemma layer 12 虽 l0=6、非常稀疏，却最难用固定 token 描述，而早层 l0=70–88 反而有大量 token-level 结构（PDF pp.7–8）。这说明稀疏度不是可解释性的充分条件。CircuitLens 聚类数也呈层级变化：layer 0 平均 1.05 簇、layer 7 4.5、layer 12 2.8、layer 21 2.95（Figure 10, PDF p.10）。layer 7 像是从词元检测转向复合电路的分界点。

8.4 超参敏感性

论文只给默认值：B=20, α=0.9, N=100, eps=0.7, min_samples=3，并做定性而非系统扫描。Appendix E.5 承认该聚类会把单义特征细分成白色衣物、绿色/黑色箱包等子簇，有时单簇反而更清楚。论文未报告 ρ、z 阈值、eps/min_samples 的完整网格、稳定区间或性能曲线，因此不能证明这些默认值跨模型稳健，也不能确定 4.5 簇是“真实多义性”还是过分裂。

8.5 统计显著性

核心论文主表给逐层均值，但未报告标准差、置信区间、随机种子、bootstrap 或显著性检验；Table 2 的每层约 250 个特征，但抽样方差未提供。故 0.01–0.03 的小差异不应当作可靠胜负；0.189 的 Clarity 差距更大、更值得复验，但也仍需独立重复。与之对照，PRISM Table 1 明确给 95% CI（例如 GPT-2 XL neuron 的 PRISM(max) AUROC 0.85，CI 0.78–0.91，PDF p.6），说明同类工作完全可以报告不确定性。

9. 真正贡献、可复用设计与迁移潜力

真正贡献一：把“输入不变结构”变成可运行基线。 Dunefsky 等只展示权重连接可解释的案例；WeightLens 将其流程化为词表投影、跨层继承、异常检测、单 token 验证与轻量词形归并。最可复用的是验证门：任何权重型解释都应经过独立运行时检查。

真正贡献二：把多义性从语义聚类改为机制聚类。 PRISM 按句向量把高激活文本聚类；CircuitLens 按共享上游特征和 (attention head, relative position) 聚类。这是关键概念迁移：两个句子语义不同但经同一电路激活，应属于一个机制簇；语义相同却走不同路径，则应拆开。

真正贡献三：明确拆开触发与后果。 输入归因回答“为什么激活”，输出归因回答“激活后做什么”。可迁移到安全监控、知识编辑与记忆分析：分别检查危险触发器、拒答/顺从输出路径，避免用同一标签混淆两端。

迁移限制： WeightLens 依赖转码器的 encoder/decoder 可分解结构，不能直接套 SAE；CircuitLens 可通过梯度归因迁到 SAE/crosscoder，但计算与“局部冻结非线性”的偏差仍在。视觉模型可把 token 换成 patch，扩散模型可把输出 token 换成时间步/噪声预测，但必须重新定义 causal intervention，而不能只复用 Jaccard 聚类。

10. 论文自述限制

  1. 架构限制（Limitations, PDF p.10）： WeightLens 专用于转码器，无法直接用于 SAE；上下文依赖特征也难捕获。
  2. 依赖未消除（Limitations, PDF p.10）： CircuitLens 减少数据规模与解释器负担，却仍依赖数据集和外部 LLM。
  3. 因果测量受冗余影响（Limitations, PDF p.10）： 转码器特征与残差 SAE 结构不同，单特征 steering 的输出影响弱，因此所有方法 Faithfulness 都低。

11. 独立批判

  1. [内部效度] 因为平均 Faithfulness 约 0.03–0.04，且最佳 Clarity 方法并未改善它，所以论文最多证明“结构信息能生成更像样的说明”，不能证明说明忠实描述了产生输出的因果机制。
  2. [评测闭环] 因为CircuitLens 用 gpt-4o-mini 生成/合并说明，FADE 又用 LLM 判断说明，且没有独立人类盲评，所以风格一致性可能同时抬高 Clarity 与 Responsiveness；应增加跨家族解释器×裁判矩阵与人类标注。
  3. [比较公平性] 因为Table 2 与 Table 3 的 MaxAct* 实际落在不同特征总体，平均 Clarity 分别 0.499 与 0.429，所以跨表宣称统一优势会混入样本选择效应；必须固定同一 feature IDs 做 paired comparison。
  4. [数据依赖] 因为24M 与 2.3B token 相差 95.8 倍，而 CL-Full 的平均 Responsiveness 从 0.519 升至 0.769，所以电路归因没有消除语料覆盖问题，只是在小数据时部分救回 Clarity。
  5. [超参/复现] 因为正文称 DBSCAN、Appendix E.5 称 HDBSCAN，并只报告 eps=0.7, min_samples=3，所以算法实现与文字之间存在复现歧义；应公开版本锁定和每层 cluster stability 曲线。
  6. [成本归因] 因为输出侧 15-token 分析为 1000 特征新增 12 A100 GPU-hour，而小数据 CL-Full 相对 CL-Input 的平均 Clarity 增益约为 0，所以默认全量输出追踪性价比不足；更合理是先用廉价指标筛选晚层候选。
  7. [外部效度] 因为主矩阵只在 Gemma-2-2B、10 个层位与 Pile 同分布语料上展开，GPT-2/Llama 主要用于 WeightLens 覆盖率，所以不能推出代码、医疗、非英语或对话语料上的稳健性。
  8. [因果定义] 因为Jacobian 归因把注意力模式与非线性在当前输入处冻结，而 Circuit Tracing 报告在注意力主导案例中归因图可“essentially useless”（项目页 Limitations），所以CircuitLens 的边是局部敏感度证据，不应直接称为全局机制；需要 activation patching/edge intervention 逐边验证。

12. 相关工作：问题来源与技术传递链

12.1 Transcoders Find Interpretable LLM Feature Circuits（Dunefsky et al., NeurIPS 2024）

解决什么： 把密集 MLP 替换成稀疏转码器，在 120M、410M、1.4B 参数模型上比较 SAE，并把跨层边分解为激活与固定权重两部分（arXiv v2, Abstract；PDF p.1）。
遗留缺口： 主要是人工案例与 GPT-2 greater-than circuit；作者承认转码器仍是近似、会丢信息，且计算限制使超参不充分（PDF pp.10–11, Limitations）。
核心如何回应： WeightLens 把固定连接的 case study 自动化，并加单 token 验证；CircuitLens 则把 prompt-specific attribution 扩展成可抽样、聚类、描述的流水线。
设计传递： activation × decoder–encoder dot product 直接进入核心 Eq.1；输入依赖/不变分离是整篇论文的代数支点。

12.2 Circuit Tracing（Ameisen et al., 2025）

解决什么： 用 cross-layer transcoder replacement model 生成单 prompt 的归因 DAG，并通过误差节点让替代模型输出与原模型局部匹配。
遗留缺口： 项目页明确指出 replacement mechanism 未必等于原模型机制；注意力主导任务可能令图失效，且 error nodes 构成“dark matter”。
核心如何回应： 采用 Jacobian 修正与注意力头 token 归因，并把单 prompt 图变成跨样本的 sparse contributor sets。
设计传递： frozen attention/normalization 的局部线性化、feature attribution graph、误差与冗余意识被继承；但核心没有把 error-node sufficiency 作为主指标。

12.3 FADE（Puri et al., ACL Findings 2025）

解决什么： 用 Clarity、Responsiveness、Purity、Faithfulness 把“好说明”分成四个可诊断维度；PDF pp.3–5 给出 Gini、自然样本分类与 steering 流程。
遗留缺口： 评测依赖合成样本、LLM judge 和特征干预；论文估计全量实验约 4,920 GPU-hour（FADE PDF Appendix，p.17）。
核心如何回应： 完整采用 FADE，避免只报一个 simulated activation score，并特别讨论低 Faithfulness。
设计传递： 四指标成为 Table 2/3 的坐标系，使“更清晰但更不纯”的权衡可见。

12.4 PRISM（Kopf et al., 2025）

解决什么： 不再强迫每个特征一个标签，而是对高激活句向量聚成 5 簇，分别描述；GPT-2 XL neuron 上 PRISM(max) AUROC 0.85 (0.78–0.91)，高于 MaxAct 0.53 (0.49–0.58)（Table 1, PDF p.6）。
遗留缺口： 聚类依据语义 embedding 而非计算路径；均值版有时显著落后 max，暴露 coverage–precision 权衡。
核心如何回应： 把聚类对象从句向量换成上游特征与注意力头模式，尝试按机制而非主题拆多义性。
设计传递： “簇级说明→合并说明”的结构直接传给 CircuitLens，但聚类准则发生关键替换。

12.5 Output-Centric Feature Descriptions（Gur-Arieh et al., ACL 2025 Main）

解决什么： 用 steering 后 token 变化或直接 unembedding 投影描述“特征把输出推向什么”；评测覆盖 2,560 个 MLP 特征，且人类评测抽取 100 个 Gemma SAE 特征（PDF pp.6,8）。
遗留缺口： 输入侧与输出侧说明经常不一致，unembedding 只给直接线性投影，难覆盖跨层间接后果。
核心如何回应： WeightLens 继承 f_dec·W_U，CircuitLens 加生成 token 的 Jacobian 归因。
设计传递： “触发—后果”双面说明成为 CircuitLens-Full；消融却显示输出侧并非总能提升平均 Clarity。

13. 开放挑战：可操作的 head-to-head 实验空白

理论

  1. 局部归因 vs 真因果边： 在同一批 feature edges 上比较 CircuitLens Jacobian、Integrated Gradients、activation patching 与 exact edge ablation；预注册边级 precision/recall、输出 KL 与任务性能恢复率。若 Jacobian 边不能预测 patching 效果，就不能叫“电路”。
  2. 聚类稳定性： 对同一特征做语料 bootstrap，比较 HDBSCAN 电路簇与 PRISM 语义簇的 adjusted Rand index、簇数方差和人类概念一致性；扫描 eps∈[0.3,0.9]、min_samples∈{2,3,5,10}，找稳定相区。
  3. 可识别性： 构造已知 ground-truth circuit 的半合成 transformer，比较 WeightLens/CircuitLens 是否在功能等价但基变换不同的表示下保持说明不变；这能检验解释是机制不变量还是坐标伪影。

工程与应用

  1. 等预算对比： 固定 20 A100-hour，比 24M CircuitLens、2.3B MaxAct*、PRISM 与 output-centric 的解释覆盖率×FADE×人工盲评；当前论文比较的数据量与计算预算不等，无法回答生产环境选谁。
  2. 选择性输出追踪： 比较“所有特征追踪 15 token”与“只对晚层/低 Clarity 特征追踪 5 token”；报告总 GPU-hour、Clarity、Faithfulness 和每 0.01 增益成本，验证能否砍掉大部分 +12 GPU-hour。
  3. 跨域迁移： 同一 Gemma 转码器在 Pile、代码、医学、中文四域分别生成说明，再交叉评测 4×4 矩阵；若跨域 Purity 崩溃，就说明权重解释也没有真正摆脱数据语境。

新兴方向

  1. 安全电路监控： 在 jailbreak/拒答对上比较 activation-only、CircuitLens 和 formal circuit verification，评估危险边召回、假阳性、攻击后迁移与实时延迟；最终目标是可验证 guardrail，而非事后漂亮标签。
  2. 训练数据→电路形成： 将 Mechanistic Data Attribution 找到的高影响训练样本与 CircuitLens 电路簇对应，删/增极少量样本后测试电路是否按预测出现或消失，建立“数据—电路—行为”三段因果链。
  3. 自动解释器代理： 用 AgenticInterpBench 的 hypothesis–validate–explain 代理与单次 gpt-4o-mini 对比；必须限制相同 token/工具预算，并以未见 circuit 的 component accuracy、validation failure rate 与人类复核时间评价。

14. 近期工作雷达

  1. Formal Mechanistic Interpretability（ICLR 2026）：把输入域鲁棒、patching 鲁棒与最小性转成验证问题，是 CircuitLens 从启发式图走向证书的直接补线。
  2. Can Language Model Agents be Helpful Circuit Explainers?：用 84 个半合成电路、163 个组件标注测试代理式解释；最有价值的结论是失败多发生在验证环，而非提出假设。
  3. Mechanistic Data Attribution：把解释对象从推理期电路向训练来源延伸，用 influence functions 追踪“哪些样本造出哪些单元”。
  4. Certified Circuits：以随机数据子采样给电路稳定性保证，直击 CircuitLens 的数据集敏感性。
  5. Causally Grounded Mechanistic Interpretability：在 GPT-2 IOI 上报告 100% sufficiency 但仅 22% comprehensiveness，提醒“找到足够解释输出的子图”不等于覆盖全部备份机制。
  6. ProxySPEX（NeurIPS 2025）：利用层级交互把 SPEX 推理次数降 10×，适合作为非转码器的稀疏交互基线。
  7. Revising and Falsifying SAE Feature Explanations（NeurIPS 2025）：用近邻负样本主动证伪过宽说明，与 WeightLens 的单 token 正向验证形成互补；下一步应把正反验证合并。

15. 结论

Circuit Insights 值得看，不是因为它已经“解释了 LLM”，而是因为它把自动解释的证据分成固定权重、输入路径与输出后果，并用统一矩阵暴露了三者不一致。最关键结果是：WeightLens 的平均 Clarity 比 MaxAct* 高 0.135（+27.05%），但 Purity 低 0.134（−20.00%）；同时所有方法 Faithfulness 仍约 0.03–0.04。对实践者而言，最佳复用策略是：先用 WeightLens 做廉价候选与验证，再把 CircuitLens 只用于上下文依赖或高风险特征，最后必须用成对干预和跨语料复验，而不能把自然语言说明当作因果证明。
