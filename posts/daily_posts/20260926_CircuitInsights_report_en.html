Circuit Insights: From Activations to Weights and Circuits

Automatic interpretation should explain why fixed weights, input paths, and output consequences agree, beyond producing fluent labels.

Daily in-depth paper tracking 2026-09-26 ICLR 2026

WeightLens improves mean Clarity over MaxAct* by 27.05%, but reduces Purity by 20.00%. Faithfulness remains around 0.03–0.04 for every method, showing a substantial gap between readable descriptions and causal credibility.

Core positioning: ICLR2026’s “Circuit Insights: Towards Interpretability Beyond Activations” divides automatic feature interpretation into complementary routes: WeightLens extracts input-invariant token relationships from transcoder weights, while CircuitLens traces input-dependent feature–attention–output interactions through attribution graphs. It substantially improves explanation clarity and reduces reliance on massive corpora, but does not resolve low Faithfulness, dependence on an explainer LLM, or causal sufficiency of circuits.

2. Motivation: the real problem is understanding why activations occur, beyond merely seeing them

Mainstream automatic-interpretation pipelines find highly activating examples for a feature in a large corpus, then give their text and per-token activations to another LLM to generate a natural-language description. This scales manual inspection to tens of thousands or millions of features, but introduces four structural problems.

First,Activations show correlation, not paths. A token co-activating with a target feature does not reveal which attention head or upstream feature mediated its contribution, nor which outputs the feature ultimately changed. Core-paper Figure 9’s L21F91 illustrates this mismatch: the input side shows only “on” or several verbs, while output attribution points to phrases such as “the basis of / based on” (PDF p.9). Activation-only analysis conflates triggering conditions with functional effects.

Second,The dataset is an implicit hyperparameter. Using the same Pile-uncopyrighted source, the paper builds a24M-token small set and 2.3B-token large set, differing by approximately 95.8 times. CircuitLens has substantially stronger input metrics on the large set, yet circuit masking plus WeightLens on 24M tokens still beats MaxAct* in Clarity (PDF pp.8,15, Table 3). Explanation quality therefore reflects not only the feature but also which corpus happens to probe it.

Third,The explainer and judge are black boxes too. CircuitLens still ultimately uses gpt-4o-mini-2024-07-18 to merge cluster descriptions, and FADE’s four metrics also rely on LLM-as-a-judge. Shared linguistic preferences between explainer and judge may reward fluency as if it were mechanistic truth. The paper acknowledges the difficulty of fully eliminating the explainer LLM (Limitations, PDF p.10).

Fourth,single-feature interventions may not test actual causal roles. Transcoder features are highly redundant, so parallel paths may compensate when one feature is steered. Mean Faithfulness in core Table 2 is only about 0.04, and most methods in Table 3 score around 0.03–0.04. This is more than a small shortfall: it signals broadly missing evidence that descriptions predict the direction of output changes.

The paper’s hypothesis is therefore narrower than “weights are inherently interpretable”: unusually strong fixed connections can supply stable semantics for context-independent features; context-dependent features require decomposition into specific upstream components and output consequences before clustering and description.

3. Narrative and key tradeoffs

The narrative consists of three shifts:

  1. From neurons to sparse features. SAEs alleviate polysemantic neurons but reconstruct only activations; transcoders reconstruct the entire MLP mapping, retaining a decomposable “input activation × fixed connection” structure.
  2. From highly activating examples to structural evidence. WeightLens directly reads encoder/decoder, embedding/unembedding, and cross-layer decoder-to-encoder connections, avoiding large corpora. CircuitLens reconstructs local circuits with input-dependent Jacobians, attention-head attribution, and output-logit attribution.
  3. From a single description to cluster-level descriptions. Examples are first clustered by shared upstream features and attention-head patterns, then described per cluster and merged. The goal is to split polysemantic features into mechanistic clusters rather than force one sentence to cover every behavior.

Costs shift accordingly: WeightLens is inexpensive and data-independent, but covers only Gemma 32.7%、GPT-2 58.8%、Llama 25.4% of verifiable token-based features (PDF p.8). CircuitLens covers contextual mechanisms but requires activation caching, backpropagation, clustering, and explainer-LLM calls; every additional output token adds forward/backward cost (Table 1, PDF p.16).

4. Equation-level formalization

4.1 Transcoders and two kinds of attribution

Let the target transcoder feature at layer l be (l,i), with encoder vector f_enc^(l,i); at an earlier layer l' , feature (l',i') has decoder vector f_dec^(l',i')and activation at token t given by a_(l',i')[t]. The simplest cross-feature attribution is:

[ A_{(l',i')\rightarrow(l,i)}(t)=a_{(l',i')}(t),\langle f_{dec}^{(l',i')},f_{enc}^{(l,i)}\rangle. ]

The first factor varies with input; the second depends only on weights. The paper further introduces a local Jacobian:

[ A^{J}{(l',i')\rightarrow(l,i)}(t)=a{(l',i')}(t),f_{dec}^{(l',i')}J^{(l\rightarrow l')}(t)f_{enc}^{(l,i)}, ]

where J Attention, normalization, and nonlinearities are locally frozen at the given input (Eq.2–3, PDF p.3). This lets CircuitLens trace paths in a particular run, but also makes it a local linear attribution rather than a globally causally equivalent account.

The contribution of attention head (l',h) from source token s to target token t to the feature is written as:

[ A_{h,s\rightarrow i,t}=\operatorname{score}{l',h}(r{pre}[t],r_{pre}[s])\cdot\langle (W_{OV}^{l',h})^Tf_{enc}^{l,i},r_{pre}^{l'}[s]\rangle. ]

On the output side, the target feature’s logit contribution to predicted token y_t is computed as:

[ A_{i\rightarrow y_t}=a_{l,i}[t], f_{dec}^{l,i}J^{y\rightarrow(l,i)}[t]W_U[:,y_t]. ]

The first three equations respectively identify fixed connections, the activation path for this input, and the direction of output influence.

4.2 WeightLens pseudocode

for layer l from early to late:
  for feature i in transcoder(l):
    input_tokens  = zscore_outliers(W_emb · f_enc[l,i], τ_vocab)
    output_tokens = zscore_outliers(f_dec[l,i] · W_U, τ_vocab)
    upstream = union over l'<l of
               zscore_outliers(W_dec[l'] · f_enc[l,i], τ_feature)
    input_tokens += inherit_validated_tokens(upstream)
    validated = {token | forward(token) activates feature(l,i)}
    if validated is empty: mark context-dependent
    else: lemmatize(validated) [+ optional output_tokens / LLM refinement]

Vocabulary outlier threshold: for GPT-2, z=4; for Gemma-2-2B and Llama-3.2-1B, z=4.5; cross-feature connection threshold z=3(PDF pp.4–5). The core assumption is that if fixed connections describe intrinsic token semantics, isolated-token forward validation should still activate the feature.

4.3 CircuitLens pseudocode

cache max activations over corpus
partition activation distribution into B=20 quantile bins
sample N=100 without replacement with weight w_i = 1 / n_bin^0.9
for each sampled context:
  trace significant upstream features and (head, token, relative-position)
  mask non-contributing input tokens
  optionally trace affected generated tokens
  form sparse contributor set S_j
filter contributors appearing in at least ρ fraction of inputs
compute Jaccard(S_a,S_b)
cluster; explain each cluster with an LLM; merge cluster descriptions

The main text says DBSCAN (PDF p.6), while Appendix E.5 says HDBSCAN,eps=0.7、min_samples=3(PDF p.21). This naming inconsistency must be clarified for reproduction.

6. Datasets, models, benchmarks, and metrics

Experiments use transcoders for GPT-2 Small, Gemma-2-2B, and Llama-3.2-1B; main quantitative results focus on Gemma-2-2B. The corpus is Pile with copyrighted material removed, totaling over 345.7 GB. The authors extract a6GB/2.3B-token large set and 40MB/24M-token small set, generate explanations on the training split, and evaluate on the test split, applying sentence-length filtering within±5%, deduplication, and numeric/symbol-only filtering (Appendix B, PDF p.15).

All four FADE metrics lie in [0,1]：

  • Clarity: whether a description is precise enough for an LLM to synthesize examples that actually activate the feature.
  • Responsiveness: whether concept-example activations separate from random/non-concept examples.
  • Purity: whether highly activating natural examples primarily match the described concept rather than unrelated content.
  • Faithfulness: whether intervening on the feature changes outputs in the claimed direction.

These should not be collapsed into one overall interpretation score. WeightLens is clear but less pure, suggesting it often captures stable token fragments while missing contextual conditions. Low Faithfulness means natural-language descriptions are not yet credible causal certificates.

8. Layered ablations, hyperparameter sensitivity, and transitions

8.1 WeightLens component ablations

Table 2 gives three combinations. WL alone has ten-layer mean Clarity of 0.634; adding output tokens lowers layer 0 from 0.67 to 0.63 and layer 12 from 0.47 to 0.38, with declines at nearly every layer. LLM summarization only partly recovers the loss. Unverified unembedding outliers thus resemble noise rather than free functional semantics. Responsiveness improves slightly for +Out , but Purity and Faithfulness do not improve systematically. The effective component is fixed connections plus single-token forward validation, not adding more words to descriptions.

8.2 CircuitLens component ablations

On small data, ten-layer mean Clarity for CL-Input and CL-Full is respectively 0.429/0.429, so output tracing adds almost no mean benefit; combining WeightLens raises it to 0.506. This contrasts sharply with Table 1’s costs:15-token output analysis adds 12 GPU-hours without improving average Clarity. In the large-data top setting, CL-Full’s Clarity exceeds CL-Input by 0.618 vs 0.609(computed by this report), a small gain. Output tracing is therefore better suited to qualitative functional localization than a default exhaustive step.

8.3 Layer-depth phase transition

The fraction verifiable by WeightLens in Gemma/Llama declines from early to middle layers, then partially recovers late. Although Gemma layer 12 has l0=6and is very sparse, it is hardest to describe using fixed tokens, while early layers with l0=70–88 show abundant token-level structure (PDF pp.7–8). Sparsity is thus insufficient for interpretability. CircuitLens cluster counts also vary by layer: layer 0 averages 1.05 clusters, and layer 7 4.5、layer 12 2.8、layer 21 2.95(Figure 10, PDF p.10). Layer 7 appears to mark a transition from token detection to composite circuits.

8.4 Hyperparameter sensitivity

The paper gives only defaults:B=20, α=0.9, N=100, eps=0.7, min_samples=3, with qualitative discussion rather than systematic sweeps. Appendix E.5 acknowledges that clustering splits monosemantic features into subclusters such as white clothing and green/black bags; sometimes one cluster is clearer.not reported by the paper ρ, z thresholds, andeps/min_samples lack complete grids, stability intervals, or performance curves. Default robustness across models is therefore unproven, and 4.5 clusters cannot be confidently interpreted as true polysemy rather than oversplitting.

8.5 Statistical significance

Main tables report layerwise means, butNot reportedstandard deviations, confidence intervals, random seeds, bootstrap estimates, or significance tests. Table 2 uses roughly 250 features per layer without sampling variance. Small0.01–0.03 differences should not determine reliable winners; the 0.189 Clarity gap is larger and worth replicating but still needs independent repeats. By contrast, PRISM Table 1 reports 95% CIs—for example GPT-2 XL neuron PRISM(max) AUROC 0.85, CI0.78–0.91 (PDF p.6)—showing that comparable work can report uncertainty.

9. Genuine contributions, reusable design, and transfer potential

Actual contribution 1: making input-invariant structure an executable baseline. Dunefsky et al. demonstrated interpretable weight connections through cases; WeightLens turns them into vocabulary projection, cross-layer inheritance, outlier detection, single-token validation, and lightweight word-form merging. The most reusable element is the validation gate: any weight-based explanation should undergo an independent runtime check.

Actual contribution 2: replacing semantic clustering with mechanistic clustering for polysemy. PRISM clusters highly activating text by sentence embeddings; CircuitLens clusters shared upstream features and (attention head, relative position) . This is a key conceptual shift: semantically different sentences activating through the same circuit should share a mechanistic cluster, while semantically similar sentences following different paths should be separated.

Actual contribution 3: explicitly separating triggers from consequences. Input attribution explains why a feature activates; output attribution explains what it does afterward. This transfers to safety monitoring, knowledge editing, and memory analysis: inspect dangerous triggers separately from refusal/compliance output paths, avoiding one label that conflates both ends.

Transfer limitations: WeightLens depends on the decomposable encoder/decoder structure of transcoders and cannot directly apply to SAEs. CircuitLens can transfer to SAEs/crosscoders through gradient attribution, but compute costs and biases from locally frozen nonlinearities remain. Vision models could replace tokens with patches, and diffusion models output tokens with timesteps/noise predictions, but causal interventions must be redefined rather than merely reusing Jaccard clustering.

10. Limitations stated by the paper

  1. Architectural limitation (Limitations, PDF p.10): WeightLens is transcoder-specific and cannot directly apply to SAEs; context-dependent features are also difficult to capture.
  2. Remaining dependencies (Limitations, PDF p.10): CircuitLens reduces data requirements and explainer burden but still depends on a dataset and an external LLM.
  3. Redundancy affects causal measurement (Limitations, PDF p.10): Transcoder features differ structurally from residual SAEs; single-feature steering weakly affects output, yielding low Faithfulness across methods.

11. Independent critique

  1. [Internal validity] Becausemean Faithfulness is around 0.03–0.04 and the best-Clarity method does not improve it,thereforethe paper establishes at most that structural information generates better-looking descriptions, not that those descriptions faithfully capture output-producing causal mechanisms.
  2. [Evaluation loop] BecauseCircuitLens uses gpt-4o-mini to generate/merge descriptions, FADE uses an LLM to judge them, and no independent blinded human evaluation is provided,thereforestylistic agreement may inflate both Clarity and Responsiveness. A cross-family explainer×judge matrix and human annotations are needed.
  3. [Comparison fairness] BecauseMaxAct* in Tables 2 and 3 actually covers different feature populations, with mean Clarity0.499 and 0.429,thereforeso a unified cross-table superiority claim would mix in selection effects; paired comparisons must fix feature IDs.
  4. [Data dependence] Because24M versus 2.3B tokens differs by 95.8×, and CL-Full mean Responsiveness rises from 0.519 to 0.769,thereforecircuit attribution has not removed corpus-coverage limitations; it only partly recovers Clarity with small data.
  5. [Hyperparameters/reproduction] Becausethe main text says DBSCAN and Appendix E.5 says HDBSCAN, reporting only eps=0.7, min_samples=3，thereforethere is reproduction ambiguity between implementation and text. Version pinning and per-layer cluster-stability curves should be released.
  6. [Cost attribution] Because15-token output analysis adds 12 A100 GPU-hours for 1000 features while small-data CL-Full adds roughly zero mean Clarity over CL-Input,thereforeexhaustive output tracing is not cost-effective by default; inexpensive screening of late-layer candidates is more reasonable.
  7. [External validity] Becausethe main matrix covers only Gemma-2-2B,10 layer positions, and in-distribution Pile data, while GPT-2/Llama mainly support WeightLens coverage analysis,thereforerobustness on code, medical, non-English, or dialogue corpora cannot be inferred.
  8. [Causal definition] BecauseJacobian attribution freezes attention patterns and nonlinearities at the current input, and Circuit Tracing reports that attribution graphs can be essentially useless in attention-dominated cases (project-page Limitations),thereforeCircuitLens edges are evidence of local sensitivity, not directly global mechanisms. Edge-by-edge activation patching/interventions are needed.

12. Related work: problem origins and technical lineage

12.1 Transcoders Find Interpretable LLM Feature Circuits（Dunefsky et al., NeurIPS 2024）

Problem addressed: Replaces dense MLPs with sparse transcoders, compares against SAEs on 120M,410M, and 1.4B-parameter models, and decomposes cross-layer edges into activation and fixed-weight factors (arXiv v2, Abstract; PDF p.1).
Remaining gap: Primarily manual cases and the GPT-2 greater-than circuit; the authors acknowledge that transcoders approximate and lose information, while compute limits restrict hyperparameter exploration (PDF pp.10–11, Limitations).
How the core paper responds: WeightLens automates fixed-connection case studies and adds single-token validation; CircuitLens extends prompt-specific attribution into a sampling, clustering, and description pipeline.
Transferred design: activation × decoder–encoder dot product Directly enters core Eq.1; separating input-dependent and invariant factors is the paper’s algebraic foundation.

12.2 Circuit Tracing（Ameisen et al., 2025）

Problem addressed: Uses a cross-layer transcoder replacement model to generate a single-prompt attribution DAG, with error nodes making replacement outputs locally match the original model.
Remaining gap: The project page explicitly notes that replacement mechanisms may differ from original-model mechanisms; attention-dominated tasks can invalidate graphs, and error nodes constitute dark matter.
How the core paper responds: Adopts Jacobian corrections and attention-head token attribution, transforming single-prompt graphs into sparse contributor sets across examples.
Transferred design: Inherits local linearization through frozen attention/normalization, feature-attribution graphs, and awareness of errors and redundancy; however, error-node sufficiency is not a primary metric in the core paper.

12.3 FADE（Puri et al., ACL Findings 2025）

Problem addressed: Divides good descriptions into four diagnostic dimensions: Clarity, Responsiveness, Purity, and Faithfulness. PDF pp.3–5 specify Gini, natural-example classification, and steering procedures.
Remaining gap: Evaluation depends on synthetic examples, an LLM judge, and feature interventions; the paper estimates full experiments at approximately 4,920 GPU-hour（FADE PDF Appendix，p.17）。
How the core paper responds: Adopts FADE in full rather than reporting only a simulated-activation score, with particular discussion of low Faithfulness.
Transferred design: The four metrics define Tables 2/3’s coordinate system, exposing the clearer-but-less-pure tradeoff.

12.4 PRISM（Kopf et al., 2025）

Problem addressed: Rather than forcing one label per feature, clusters highly activating sentence embeddings into 5 groups and describes each. On GPT-2 XL neurons, PRISM(max) AUROC is 0.85 (0.78–0.91), above MaxAct’s 0.53 (0.49–0.58)（Table 1, PDF p.6）。
Remaining gap: Clustering uses semantic embeddings rather than computation paths. The mean variant sometimes substantially underperforms max, revealing a coverage–precision tradeoff.
How the core paper responds: Replaces sentence embeddings with upstream features and attention-head patterns, attempting to split polysemy by mechanism rather than topic.
Transferred design: The cluster-description→merged-description structure transfers directly to CircuitLens, with a crucial change in clustering criterion.

12.5 Output-Centric Feature Descriptions（Gur-Arieh et al., ACL 2025 Main）

Problem addressed: Uses post-steering token changes or direct unembedding projections to describe output influence; evaluation covers 2,560 MLP features, with human evaluation sampling100 Gemma SAE features (PDF pp.6,8).
Remaining gap: Input- and output-side descriptions often disagree; unembedding supplies only a direct linear projection and misses indirect cross-layer effects.
How the core paper responds: WeightLens inherits f_dec·W_U, while CircuitLens adds Jacobian attribution over generated tokens.
Transferred design: Two-sided trigger–consequence descriptions become CircuitLens-Full; ablations nevertheless show that output analysis does not always improve average Clarity.

Three shifts drive this evolution: from whether a neuron resembles a concept to whether sparse features are more monosemantic; from whether descriptions resemble activating examples to whether they explain output consequences; and from semantic similarity between sentences to shared computation paths. This paper occupies the third shift but has not reached formal verification or counterfactual causal certificates.

13. Open challenges: actionable head-to-head experiment gaps

Theory

  1. Local attribution versus true causal edges: Compare CircuitLens Jacobians, Integrated Gradients, activation patching, and exact edge ablation on the same feature edges. Preregister edge-level precision/recall, output KL, and task-performance recovery. If Jacobian edges cannot predict patching effects, calling them circuits is unwarranted.
  2. Clustering stability: Bootstrap the corpus for each feature; compare HDBSCAN circuit clusters with PRISM semantic clusters using adjusted Rand index, cluster-count variance, and human concept agreement. Sweep eps∈[0.3,0.9]、min_samples∈{2,3,5,10}to locate stable regimes.
  3. Identifiability: Build semi-synthetic Transformers with known ground-truth circuits and test whether WeightLens/CircuitLens descriptions remain invariant under functionally equivalent basis changes. This distinguishes mechanistic invariants from coordinate artifacts.

Engineering and applications

  1. Equal-budget comparison: Fix20 A100-hours and compare24M CircuitLens,2.3B MaxAct*, PRISM, and output-centric methods on explanation coverage×FADE×blinded human evaluation. Unequal data and compute budgets in the paper cannot determine the best production choice.
  2. Selective output tracing: Compare tracing 15 tokens for every feature with tracing 5 tokens only for late-layer/low-Clarity features. Report total GPU-hours, Clarity, Faithfulness, and cost per0.01 gain to test whether most of the additional12 GPU-hours can be eliminated.
  3. Cross-domain transfer: Generate descriptions for the same Gemma transcoder on Pile, code, medicine, and Chinese, then evaluate a4×4 cross-domain matrix. If cross-domain Purity collapses, weight-based explanations have not escaped data context.

Emerging directions

  1. Safety-circuit monitoring: Compare activation-only, CircuitLens, and formal circuit verification on jailbreak/refusal pairs. Evaluate dangerous-edge recall, false positives, post-attack transfer, and real-time latency. The goal is a verifiable guardrail, not attractive retrospective labels.
  2. Training data→circuit formation: Map influential training examples found by Mechanistic Data Attribution to CircuitLens clusters; remove/add very few examples and test whether circuits appear or disappear as predicted, establishing a data–circuit–behavior causal chain.
  3. Agentic automatic explainers: Compare AgenticInterpBench’s hypothesis–validate–explain agent with a single gpt-4o-mini under equal token/tool budgets. Evaluate component accuracy on unseen circuits, validation-failure rate, and human-review time.

14. Recent-work radar

  1. Formal Mechanistic Interpretability（ICLR 2026）: formalizes input-domain robustness, patching robustness, and minimality as verification problems, directly bridging CircuitLens’s heuristic graphs toward certificates.
  2. Can Language Model Agents be Helpful Circuit Explainers?: evaluates agentic interpretation with 84 semi-synthetic circuits and 163 component annotations. Its most useful finding is that failures arise more often in validation than hypothesis generation.
  3. Mechanistic Data Attribution: extends interpretation from inference-time circuits to training origins, using influence functions to trace which examples form which units.
  4. Certified Circuits: provides circuit-stability guarantees through random data subsampling, directly addressing CircuitLens’s dataset sensitivity.
  5. Causally Grounded Mechanistic Interpretability: reports 100% sufficiency but only 22% comprehensiveness on GPT-2 IOI, reminding us that a subgraph sufficient to explain outputs need not cover every backup mechanism.
  6. ProxySPEX（NeurIPS 2025）: uses hierarchical interactions to reduce SPEX inference calls10×, making it a useful non-transcoder sparse-interaction baseline.
  7. Revising and Falsifying SAE Feature Explanations（NeurIPS 2025）: actively falsifies overly broad descriptions using nearest-neighbor negatives, complementing WeightLens’s positive single-token validation. Combining positive and negative validation is a natural next step.

15. Conclusion

Circuit Insights is valuable because it separates automatic-interpretation evidence into fixed weights, input paths, and output consequences, exposing their disagreements in one matrix—not because it has finished explaining LLMs. The key result is that WeightLens mean Clarity exceeds MaxAct* by 0.135（+27.05%）, while Purity is lower by 0.134（−20.00%）; Faithfulness remains around 0.03–0.04 for all methods. A practical strategy is to use WeightLens for inexpensive candidate generation and validation, reserve CircuitLens for context-dependent or high-risk features, and finish with paired interventions and cross-corpus replication. Natural-language descriptions must not be treated as causal proof.
