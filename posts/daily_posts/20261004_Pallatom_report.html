Pallatom

把序列—结构共设计推进到全原子联合生成

PMLR 267:50786–50816 2026-10-04 Atom14 · EDM · Recycling

Atom14 坐标扩散与原子回收把 CO-DESIGN DES-aa 从 MultiFlow 的 62.74% 提升到 85.03%，并将结构簇从 134 增至 291；但 L=400 时被 CarbonNovo 反超 20.9 pp，高步长出现 92% 全螺旋偏置，且没有湿实验。

一句话核心定位：Pallatom 用固定尺寸 Atom14 点云、坐标扩散与结构回收，在不知道侧链元素类型的前提下直接学习蛋白质序列与全原子构象的联合分布；它显著抬高 60–120 aa 的计算共设计成功率与结构多样性，但长链退化、二级结构偏置、代理评测闭环和缺少湿实验，使它更像一条被验证可行的工程路径，而非已经闭环的蛋白设计平台。

2. Motivation：真正的痛点不是“多画几颗原子”

主流蛋白生成器往往拆成两步：先生成骨架，再用 ProteinMPNN 一类逆折叠器补序列，最后用结构预测器检查自洽。这条流水线把联合分布 (p(\text{sequence},\text{all-atom coordinates})) 切成若干条件分布，工程上成熟，却有三个具体缺口。

第一，侧链不是可忽略的渲染层。活性位点、氢键网络、疏水核心与配体接触由侧链原子决定；只建模 Cα 或主链时，模型可以交出“看似可折叠”的骨架，却没有在生成阶段承担原子碰撞与侧链化学一致性的代价。第二，序列和结构存在强耦合。先骨架后序列会把早期几何错误推给下游修补；若某个骨架只对极窄序列集合可设计，骨架指标可能仍然漂亮。第三，已有全原子表示代价高或语义复杂：例如 Protpardelle 的 atom73 表示需要在多个候选侧链身份上叠加坐标，离散氨基酸身份与连续坐标在反向过程中相互缠绕。

论文的量化证据很直接。主实验对 60、70、80、90、100、110、120 aa 七个长度各采样 250 个，共 1,750 个候选。最强全原子/共设计基线 MultiFlow 的 CO-DESIGN DES-aa 为 62.74%，Pallatom 为 85.03%，绝对增加 22.29 pp，相对增加 35.53%；Foldseek 结构簇由 134 增到 291，增加 157 个、相对 117.16%；MMseq2 序列簇由 1,042 增到 1,466，增加 424 个、相对 40.69%（Table 1，PDF p.7）。这说明全原子联合建模并未自动牺牲多样性，反而能扩大可设计区域。

但动机也不能被夸大成“全原子必然优于骨架路线”。在 ProteinMPNN 后处理的 DES-bb 指标上，Pallatom 89.89%，低于 ProteinGenerator 的 93.14%，差 3.25 pp（Table 1，p.7）。所以论文支持的是：在作者定义的共设计协议里，全原子联合分布更好；它不支持“所有设计场景都统治两阶段方法”。

3. 故事线、核心假设与权衡

故事线可以压缩成四步。

  1. 统一表示：把每个残基写成固定 (14\times3) 坐标块。真实存在的原子放入对应槽位，缺失侧链原子临时填在 Cα 上；生成开始时只知道主链元素类型，侧链槽位都是 UNK。
  2. 先几何、后身份但在同一网络内闭环：坐标扩散网络输出去噪后的 Atom14 几何；SeqHead 从几何预测 20 类氨基酸并据此裁掉虚拟槽位。与外接 ProteinMPNN 不同，序列头和几何主干共同训练。
  3. 全局—局部分轨：残基层 Transformer 捕获远程拓扑，原子层模块处理近邻几何；AtomDecoder 再把当前去噪坐标转成新的 pair 表征，回灌主干。
  4. 用可微结构代理塑形：原子回归、序列交叉熵、smooth-LDDT、残基/原子 distogram 与中间层损失共同训练；采样用 200 步一阶 Euler。

核心假设是：固定 Atom14 槽位虽在化学上冗余，却能把变长侧链变成固定张量，使等变几何学习的收益大于 UNK 与虚拟 Cα 点引入的歧义。第二个假设是：回收（recycling）比一次性从噪声预测更重要，因为残基身份、侧链几何与局部邻域要反复协商。第三个假设是：代理设计性指标能大致筛出实验上有希望的蛋白。前两项得到消融支持，第三项没有湿实验验证。

权衡也很清楚：固定槽位换来简单并行化，却牺牲显式化学身份；大步长 η 提高去噪推进速度和长链成功率，却把样本推向 α-螺旋吸引域；200 步 Euler 带来约 10–58 秒的采样速度，却没有证明这是质量—成本 Pareto 前沿。

4. 方程级形式化与采样流程

4.1 EDM 坐标扩散

设干净全原子坐标为 (y\in\mathbb{R}^{N\times14\times3})，噪声为 (n\sim\mathcal N(0,\sigma^2I))，(x=y+n)。论文采用 Elucidating the Design Space of Diffusion Models（EDM）形式：

[ p_t(x)=\leftp_{\text{data}} * \mathcal N(0,\sigma(t)^2I)\right,\qquad \sigma(t)=t,\ s(t)=1. ]

概率流 ODE 为（Eq. 1，PDF p.3）：

[ d x=-\sigma(t)\nabla_x\log p(x;\sigma(t)),dt. ]

去噪器以加权均方误差训练（Eq. 2，p.3）：

[ \mathbb E_{y,n}\big[\lambda(\sigma)|D_\theta(y+n;\sigma)-y|_2^2\big], ]

其隐式 score 为（Eq. 3，p.3）：

[ \nabla_x\log p(x;\sigma)=\frac{D_\theta(x;\sigma)-x}{\sigma^2}. ]

EDM 预条件（Eq. 4）写成：

[ D_\theta(x;\sigma)=c_{\text{skip}}(\sigma)x+c_{\text{out}}(\sigma) F_\theta(c_{\text{in}}(\sigma)x,c_{\text{noise}}(\sigma)). ]

Pallatom 的第 (k) 次回收直接在坐标层混合输入与更新（Eq. 5，p.4）：

[ r_{\text{denoised}}^{(k)}=c_{\text{skip}}(t)r_{\text{input}}+ c_{\text{out}}(t)r_{\text{updates}}^{(k)}. ]

基础目标（Eq. 6）与完整目标（Eq. 7，p.5）为：

[ \mathcal L_0=\lambda(t)\mathcal L_{\text{atom}}+\alpha_0\mathcal L_{\text{seq}}, ]

[ \mathcal L=\mathcal L_0+\alpha_1\mathcal L_{\text{smooth-LDDT}}+ \alpha_2\mathcal L_{\text{res-dist}}+ \alpha_3\mathcal L_{\text{atom-dist}}+ \alpha_4\mathcal L_{\text{intermediate}}. ]

4.2 伪代码

输入：长度 N，T=200，η=2.25，γ=0.2，t∈[0.01,1]
初始化：Atom14 坐标 x_T ~ N(0, σ_T²I)；侧链身份全部 UNK
for i = T ... 1:
    1. 用残基级全局轨 + 原子级局部轨编码 x_i
    2. MainTrunk 第一次去噪，得到坐标与 pair 表征
    3. AtomDecoder 从去噪坐标重建 distogram，回灌 MainTrunk
    4. MainTrunk 第二次去噪，SeqHead 同时预测残基身份
    5. 由 EDM score 计算 Euler 更新；用 η 与 γ 调节步长/噪声
end
按预测残基类型裁掉虚拟侧链槽位，输出序列与全原子坐标

关键不是“再加一个序列分类头”，而是步骤 3：当前几何被重新编码成关系特征，再改变下一轮几何与序列判断。Table 3 的去回收消融把 DES-aa 从 87% 打到 21%，说明闭环而非 Atom14 名字本身，是性能主轴。

6. 数据集、基准与指标

训练 PDB 部分过滤分辨率小于 3Å、95% 序列同一性，并移除 loop 占比超过 50% 的结构，剩 7,459。AFDB-cluster 从标称 2.14 亿规模库出发，先按平均 pLDDT≥80、长度≤128 得 582,652，再用邻域密度≥20、核心残基比例≥30%、片段数≥4、回转半径<25、最大 loop≤15 及 Foldseek TM 0.8/coverage 0.9 等条件过滤约 30% 近重复，最终取 27,697。每 epoch 合计 35,156（§4.1、Appendix B，pp.6,19–20）。这里“2.14 亿”是上游数据库规模，不是 Pallatom 真正训练样本数。

最有价值的归因是：去掉 recycling 后，骨架经 ProteinMPNN 修复仍有 93–95% DES-bb，但端到端 DES-aa 只剩 21%。这表明回收主要解决“模型自己生成的序列是否匹配自己的侧链几何”，而非基本骨架拓扑。smooth-LDDT 的边际收益仅 3 pp；论文没有给多随机种子，因此不能判断这 3 pp 是否稳定。

把 η 从 1.75 提到 2.75，DES-aa 增 37 pp（相对 64.91%）；但继续到 3.25 不再增益，且 DIV-str 相比默认 2.25 从 64 降到 46（−28.13%）。把 γ 从 0.2 降到 0.1 在同样 η=2.25 时 DES-aa 只增 2 pp，却让多样性从 64 降到 52（−18.75%），同时螺旋占比从 28% 升到 45%。因此默认设置不是单指标最优，而是 Pareto 折衷。

更明显的相变出现在 OOD 长度。Table 7（p.24）中，η=3.0 在 L=400 把 DES-aa 从 η=2.5 的 4% 提到 18%，但 HHH 从 69% 提到 92%，HEL 从 31% 压到 8%，EEE 为 0。因为成功率提升几乎伴随全螺旋化，所以高 η 可能在利用评测器容易接受的低复杂度结构，而非真正解决长链联合设计。

8.3 统计显著性

论文只对推理时间报告均值±标准差（Table 16）；DES、DIV、NOV、消融和超参表均未报告跨随机种子标准差、置信区间、显著性检验或 bootstrap。主评估每长度 250 样本，消融每配置 100 样本。由此能判断 22.29 pp 主差距很大、工程意义明显；不能判断 2–3 pp 的小差异是否稳健，也不能把多样性簇数当独立同分布样本做常规 t 检验。

9. 真正贡献、可复用设计与迁移潜力

真正贡献一：固定槽位不是终点，而是让连续坐标扩散承载离散化学的桥。 Pallatom 没有直接扩散氨基酸 token，而是让几何先形成、SeqHead 再选择哪些槽位真实存在。这一做法简单，却把最难的可变维度问题改写为掩码问题。

真正贡献二：全原子回收是可复用的闭环模块。 Table 3 的 −66 pp 说明，把当前生成坐标转成 pair/distogram 再反馈，比单次端到端预测重要。这个模式可迁移到配体—蛋白复合物、RNA 三级结构和材料晶胞：生成状态经可微几何摘要后，重新条件化下一步去噪。

真正贡献三：论文诚实暴露了采样相变。 Table 2 与 Table 7 让读者看到 η 既是数值积分参数，也是形态先验旋钮。这比只报告最佳超参更有科学价值。

迁移时应保留“局部原子轨 + 全局实体轨 + 回收”，但不必照搬 Atom14。复合物可用残基/链/原子三层图；小分子可用元素与键显式状态；长蛋白更适合 La-Proteina 式部分潜变量，把高频侧链细节压缩后再由解码器恢复。若任务强调功能，应把活性位点几何、能量或实验标签加入条件，而不是只优化自洽折叠。

10. 相关工作：问题来源与技术传递链

10.1 RFdiffusion：从结构预测器到骨架生成器

解决什么：RFdiffusion 把 RoseTTAFold 表征改造成 SE(3) 结构扩散器，证明骨架生成与 motif scaffolding 可达到实验验证层面。遗留缺口：输出以骨架为中心，序列与侧链通常交给 ProteinMPNN/packing 工具，联合分布被切开。Pallatom 如何回应：把侧链槽位与序列头并入扩散主干。关键设计如何传递：结构预测网络的 pair/single 表征与 recycling 思想被保留，但状态从 backbone frame 扩展为 Atom14 坐标。

10.2 Protpardelle：显式全原子扩散的直接前驱

解决什么：用 atom73 表示叠加各种可能侧链原子，直接生成全原子蛋白。遗留缺口：候选原子多、身份坍缩过程复杂，计算与表示冗余。Pallatom 如何回应：用每残基 14 个槽位把维度降下来，以 SeqHead 决定最终氨基酸和保留原子。设计传递：保留“坐标先承载序列信息”的连续建模观，但把离散身份解析后置到可学习头。

10.3 MultiFlow：离散序列 + 连续结构的联合流

解决什么：把离散序列 CTMC 与连续 SE(3) 流匹配统一训练，直接共设计 backbone 与 sequence。遗留缺口：侧链几何不在联合状态里，DES-aa 仍需外部全原子解释。Pallatom 如何回应：把结构变量提升到全部重原子坐标。设计传递：共同建模序列—结构、非自回归并行生成被继承，但 Pallatom 选择“连续几何 + 终端分类头”而非显式离散扩散。

10.4 La-Proteina：对 Pallatom 可扩展性缺口的后续回应

解决什么：用显式 Cα 加每残基固定 8 维潜变量表示序列与原子细节，在部分潜空间做 flow matching；论文报告训练于 4600 万序列—结构对并生成到 800 aa（arXiv:2507.09466v1，§2–3）。遗留缺口：潜变量牺牲了中间去噪态的直接物理可解释性，训练数据与模型规模远大于 Pallatom。如何回应 Pallatom：它绕过 Atom14 在长链上的 (O(N\times14)) 显式负担，直接瞄准 Pallatom L=350/400 的崩落。设计传递：固定维度和联合流仍在，但“固定维度”从原子槽位变为潜变量，是从显式全原子到部分潜变量的转折。

11. 论文自述限制

  1. 任务范围：讨论部分明确把更一般的架构与复杂体系列为未来工作（Discussion，PDF p.9）；当前实验以单体、无条件设计为主，不能外推到复合物、膜蛋白或含配体体系。
  2. 尺度限制：训练 crop 为 128（Table 6，p.20），虽然附录测试到 400 aa，但 Table 8 显示 350 后落后 CarbonNovo。这是论文数据本身承认的外推边界。
  3. 验证限制：正文只做计算设计性、结构多样性与新颖性评估，没有表达、稳定性、结合或功能湿实验。论文因此只能声称 in-silico designability。

12. 独立批判（证据 → 推论）

  1. [评测有效性] 因为 DES-aa 用 ESMFold pLDDT 与 aaRMSD 定义，而训练数据又大量来自 AFDB 高 pLDDT 结构，所以生成器和评测器共享结构预测生态的偏好；因此 85.03% 更可靠地表示“被当前预测器判为自洽”，不能直接等价为实验可折叠率。
  2. [长程泛化] 因为训练 crop 128，而 DES-aa 从 L=200 的 93.3% 降到 L=400 的 17.9%，并在 L=400 落后 CarbonNovo 20.9 pp；因此 残基层全局轨尚未学到真正长度稳健的拓扑先验。
  3. [模式坍缩] 因为 η=3.0、L=400 时 HHH 达 92%、EEE 为 0，而较小 η 只有 4% DES-aa；因此 提高步长得到的部分成功率很可能来自螺旋化捷径，不能当成无代价的采样加速。
  4. [归因不足] 因为无 recycling 将 DES-aa 降 66 pp，但论文没有等计算预算的“更多层数/更多参数、无回收”对照；因此 可以认定回收实现有效，不能严格认定增益来自迭代语义而非额外前向计算。
  5. [资源与复现] 因为代码仓库提供训练数据管线与采样命令，却未找到作者训练权重和整理后的 35,156 样本快照；因此 第三方可以重建流程，但难以逐位复现 Table 1，也无法排除数据库版本差异。
  6. [统计] 因为主表、消融和超参没有随机种子方差/置信区间，只有推理时间报告标准差；因此 22.29 pp 的主差距可信度较高，而 2–3 pp 的 smooth-LDDT 或 γ 差异不应被当作稳定结论。
  7. [成本口径] 因为训练消耗约 960 A6000 GPU-hour，但论文未报告参数量、峰值显存、碳排与从数据库预处理开始的总成本；因此 10.2 秒采样不能证明整套方法更“高效”。
  8. [生物功能] 因为所有核心结果都在无条件单体与结构代理上，且没有活性位点、结合能或实验功能读出；因此 “protein design”在本文更准确是“可折叠结构—序列共设计”，而不是面向功能的蛋白工程闭环。

13. 开放挑战：可执行的 head-to-head 实验空白

13.1 理论

  • 显式坐标 vs 部分潜变量：在同一 35,156 训练集、同参数量、同 960 GPU-hour 预算下，比较 Pallatom Atom14 与 La-Proteina 式 8D/残基潜变量；按长度 100–800 同时报告 DES-aa、clash、Ramachandran、DIV 与每步 FLOPs。这样才能判断长链优势来自表示，还是来自数据规模。
  • 回收 vs 计算量：把 Pallatom 两次 MainTrunk/步与“无回收但宽度增大、总 FLOPs 相等”模型 head-to-head；若前者仍领先，才说明几何反馈本身而非计算量导致 66 pp 增益。
  • 采样相变：对 η∈[1.5,3.5]、γ∈[0,0.3] 做二维网格，每点至少 5 个随机种子；用二级结构熵、DES-aa 与去重后有效样本数刻画相边界，而不是只挑五个点。

13.2 工程与应用

  • 端到端时间/质量 Pareto：在同一 RTX 4090、相同长度、相同最终原子数和相同有效样本数下，比较 Pallatom、MultiFlow+ProteinMPNN+packing、Protpardelle 与 La-Proteina；计入后处理、失败重采样和结构预测评估成本。
  • 可复现训练：作者发布冻结版训练清单、权重与容器后，由独立团队在 4×A6000 重训；以 Table 1 的 DES-aa、DIV-str 预注册 ±2 pp/±10% 复现区间。当前缺失权重时，这项实验无法完成。
  • 湿实验盲测：从 Pallatom、RFdiffusion+ProteinMPNN、La-Proteina 各选 100 个长度匹配、代理分数匹配且去重的设计，盲测表达、单分散、热稳定性和结构；把“预测器通过率”与“实验成功率”画校准曲线。

13.3 新兴方向

  • 复合物联合生成：在同一 PPBench 拆分上比较 Pallatom 扩链版、APM 与 PPDiff，要求零样本新靶点、界面侧链 clash、Rosetta ΔΔG、AF-Multimer 置信度及湿实验 binder 命中率；避免只比较不同数据集的内部成功率。
  • 动力学条件化：把 NMA-tune 的最低频 normal mode 条件接入 Pallatom 回收层，与只改 backbone 的 NMA-tune 对比 MD 中目标模态重合、侧链熵和 DES-aa，检验全原子是否真正改善动态可设计性。
  • 生成—理解对齐：用同一 Protpardelle/Pallatom 主干，对比纯去噪与加入蛋白理解编码器表示对齐；在 MotifBench、全原子共设计和突变效应预测上共同评估，避免只优化一种生成指标。

14. 近期工作雷达

  1. La-Proteina: Atomistic Protein Generation via Partially Latent Flow Matching（2025-07-13）：用 Cα 显式坐标加 8D/残基潜变量报告可扩到 800 aa，是对 Pallatom 长链崩落最直接的后续路线；但大规模 4600 万对训练数据使公平对比困难。
  2. An All-Atom Generative Model for Designing Protein Complexes（arXiv v1, 2025-04-17；ICML 2025）：APM 把全原子生成扩到多链复合物，并公开 代码；它补上 Pallatom 单体局限，但需要严格的新靶点拆分排除复合物泄漏。
  3. PPDiff（ICML 2025）：用序列—结构交错网络和因果注意力联合设计 binder，报告预训练/mini-binder/抗体任务成功率 50.00%、23.16%、16.89%；方向更功能化，但没有等口径全原子单体对标。
  4. NMA-tune（ICML 2025）：把最低 normal mode 条件作为 RFdiffusion 插件并用 MD 检查目标动力学；说明“可折叠”之后的下一步是“会按目标方式运动”。
  5. FAMPNN（ICML 2025）：在固定骨架逆折叠中联合残基身份与侧链构象，证明全原子信息也能提升零样本稳定性/结合预测；它与 Pallatom互补，一个强调条件化设计，一个强调从噪声生成。
  6. Consistent Synthetic Sequences Unlock Structural Diversity in Fully Atomistic De Novo Protein Design（2025-12-01）：通过 ProteinMPNN 与结构预测器构造更一致的合成序列—结构对，报告 La-Proteina 结构多样性 +54%、共设计性 +27%；它提示数据配对质量可能比模型表示更关键。
  7. Exploring the Alignment of Generation and Understanding in Protein Structure Modeling（2026-07-15）：把生成器对齐到理解编码器，报告 Protpardelle-1c 的 MotifBench 从 39.2 到 47.1（相对 +20%）；这是把结构生成从几何自洽推向功能表征的一条新轴。

15. 结论

Pallatom 值得读，不是因为它最终解决了全原子蛋白设计，而是因为它用极简的 Atom14 固定槽位与强回收机制证明：显式坐标可以在不维护复杂离散扩散状态的情况下承载序列—侧链耦合。主表的 +22.29 pp DES-aa 与 2.17× 结构簇 是扎实进展；Table 3 的 −66 pp 无回收崩落 揭示真正机制；Table 7/8 的长链与螺旋相变则清楚划出边界。

最合理的研究判断是：把 Pallatom 视为“显式全原子联合生成”的强基线和模块库，而非湿实验已验证的平台。下一步最值得做的不是继续抬高 ESMFold 通过率，而是在等数据、等算力条件下比较显式与潜变量表示，并用盲测湿实验校准计算代理。
